# AI Radar LLM Wiki — 설계 문서

날짜: 2026-07-06 · 상태: 승인됨

## 목적

최신 AI 트렌드 — 특히 Claude Code, Codex, ChatGPT, Gemini의 중요 업데이트와 신기능 — 를
지속 추적하는, LLM(Claude Code)이 유지·관리하는 개인 위키.

활용처 (MECE 아님 — 하나의 자료가 여러 활용처에 동시 사용됨):
1. AI 학습과정 기획 소재
2. 데일리 뉴스레터
3. 기업 AX 추진 부서의 전략수립 근거자료

## 확정된 핵심 결정

| 결정 | 선택 |
|---|---|
| 수집 방식 | 하이브리드: 자동 스캔 → 뉴스레터(=승인 인터페이스) → 사용자 승인 항목만 위키 반영 |
| 언어 | 한국어 (고유명사 영문 유지) |
| 뉴스레터 | 위키 내 파일 (`newsletter/YYYY-MM-DD.md`) |
| 열람 도구 | Obsidian (vault = 이 폴더), 위키링크 형식 |
| 활용처 표현 | 분류가 아닌 뷰: frontmatter `uses` 복수 태그 + 요청 시 outputs/ 산출물 생성 |

## 아키텍처

원본 아이디어 문서의 3레이어를 따른다:
- **raw/** — 불변 원본 소스 (월별 폴더 + assets)
- **wiki/** — Claude가 관리하는 지식 레이어 (tools / updates / concepts / players / use-cases / analysis / timeline)
- **CLAUDE.md** — 스키마 (구조·규칙·워크플로우). 상세 규칙은 CLAUDE.md가 단일 진실 원천.

`wiki/updates/`가 심장: 업데이트 1건 = 페이지 1개, 도구 허브 페이지가 최신 종합을 유지.

## 데일리 운영 루프

1. **Scan (자동, 매일 아침)** — 스케줄된 에이전트가 sources.md의 소스를 훑어 뉴스레터 초안 생성.
   각 항목에 체크박스 + 출처 링크.
2. **승인 (사람, ~5분)** — 뉴스레터를 읽고 반영할 항목 체크 또는 구두 지시.
3. **Ingest (Claude)** — 원문 저장 → updates 페이지 생성 → 허브·개념·타임라인·인덱스 갱신.
4. **Lint (주 1회)** — 위키 건강검진.

## 소스

- 공식 블로그·체인지로그 10곳 (Anthropic, OpenAI, Google)
- Reddit 4곳 + Hacker News
- YouTube 11채널 (한국어 4, 영어 7) — 제목 스캔 → 승인 시 자막 수집 2단계
- X/Instagram: 로그인 장벽으로 웹서치 간접 포착 + 사용자 URL 전달 병행

전체 목록은 `sources.md`.

## 구축 순서

1. ✅ 골격 + 스키마 파일 + git init
2. 도구 허브 페이지 4개를 웹서치 기반 현재 스냅샷으로 초기화
3. 첫 스캔 수동 실행 → 첫 뉴스레터 → 사용자와 형식 검토
4. 형식 안정 후 데일리 스케줄 등록
