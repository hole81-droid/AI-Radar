## 에이전트 구축 · 업무 자동화 ★최우선
- [ ] **Codex로 이메일·왓츠앱·캘린더를 한 번에 처리하는 "개인 비서 에이전트" 구축기** — 한 사람이 Codex를 중심으로 여러 메신저·구글 워크스페이스를 엮어 개인 업무 자동화 스택을 만든 실전 후기. [원문](https://nicolasbustamante.com/blog/how-agents-run-my-personal-life)
    - **도구**: OpenAI Codex + Google Workspace CLI(gogcli) + WhatsApp CLI(wacli) + Telegram/iMessage 연동 + 브라우저·macOS 자동화
    - **자동화한 업무**: 이메일 작성·발송, 여러 메신저(왓츠앱·텔레그램·아이메시지)를 가로지르는 "무엇을 놓쳤나" 확인, 소개 이메일 초안 작성, 구글 드라이브 문서 갱신, 캘린더 일정 생성
    - **방법**: API/CLI 우선 → 로컬 파일 → 브라우저 자동화 → 화면 자동화 순으로 도구를 계층화하고, 구글 드라이브를 중앙 데이터 소스로 삼음. 중요한 메시지는 "초안까지만 만들고 사람이 승인" 하는 권한 단계를 둬서 오작동을 방지.
    - **포인트**: 20분 걸리던 멀티앱 작업을 약 10초로 줄였다고 주장. 승인 게이트를 둔 설계가 재현 시 안전장치로 참고할 만하다. 기업 개인비서 자동화 강의 소재로 적합.
