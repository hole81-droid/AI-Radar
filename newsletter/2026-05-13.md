# AI Radar 데일리 — 2026-05-13

## 오늘의 헤드라인
Anthropic이 소상공인을 겨냥한 "Claude for Small Business"를 발표하며, 15개 워크플로우·15개 스킬로 급여·결산·송장 추적 같은 업무를 즉시 자동화할 수 있게 했습니다.
Claude Code에 "완료 조건을 걸어두면 그 조건이 충족될 때까지 스스로 계속 작업하는" `/goal` 명령이 등장해 자율 개발 루프 시대를 열었습니다.
동시에 Anthropic은 6/15부터 `claude -p`·Agent SDK 같은 비대화형 사용을 구독제에서 떼어내 별도 크레딧으로 과금하겠다고 발표했고, "Claude Design 구독을 취소하자마자 프로젝트 접근권을 잃었다"는 글이 HN에서 126점을 얻으며 논쟁이 커졌습니다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [x] **Anthropic, 소상공인 전용 "Claude for Small Business" 발표** — [Anthropic](https://www.anthropic.com/news/claude-for-small-business)
    - **도구**: Claude + QuickBooks·PayPal·HubSpot·Canva·Docusign·Google Workspace·Microsoft 365 연동
    - **자동화한 업무**: 급여 계획, 월말 결산, 판매 캠페인 운영, 송장 추적 등 소상공인이 매일 반복하는 사무 업무
    - **방법**: 이미 쓰고 있는 도구에 바로 붙는 15개 즉시 사용 가능한 워크플로우와 15개 스킬을 패키지로 제공. 별도 개발 없이 기존 업무 도구 위에 얹는 구조.
    - **포인트**: 미국 GDP의 44%를 차지하는 소상공인은 지금까지 AI 도입에서 대기업보다 뒤처져 있었는데, "완제품 워크플로우 패키지"로 그 격차를 좁히려는 시도다. 강의에서 "비개발자가 바로 쓸 수 있는 자동화"의 대표 사례로 활용 가능.
- [x] **Claude Code, 완료 조건이 충족될 때까지 스스로 반복하는 `/goal` 명령 도입** — [공식 문서](https://code.claude.com/docs/en/goal) · [Hacker News](https://news.ycombinator.com/item?id=48159960)
    - **도구**: Claude Code `/goal` 명령(세션 범위 Stop 훅의 래퍼)
    - **자동화한 업무**: "test/auth의 모든 테스트가 통과하고 lint가 깨끗할 때까지" 같은 검증 가능한 종료 조건이 있는 대규모 작업(API 마이그레이션, 설계 문서 구현, 이슈 백로그 소진 등)
    - **방법**: 매 턴이 끝나면 작은 고속 모델(기본 Haiku)이 조건 충족 여부를 판단해 "아니오"면 이유를 알려주며 다음 턴을 계속 진행시키고, "예"면 자동으로 멈춤. `claude -p "/goal ..."` 형태로 비대화형(headless) 실행도 가능해 무인 파이프라인에 바로 넣을 수 있음.
    - **포인트**: 사람이 매 턴 프롬프트를 다시 치지 않아도 되는 진짜 "자율 개발 루프"의 표준 인터페이스가 생겼다는 의미. 시간/턴 제한 조건("20턴 후 중단")을 같이 걸 수 있어 무인 실행 시 폭주를 막는 안전장치도 내장돼 있다.

## 빅 뉴스
- [ ] **Anthropic, 6/15부터 Claude Code 비대화형 사용을 구독 한도에서 분리 — 별도 크레딧으로 API 요금 과금** — `claude -p`, Claude Agent SDK, Claude Code GitHub Actions, Agent SDK로 인증하는 서드파티 앱이 6/15부터 구독 한도가 아닌 별도 월간 크레딧(Pro $20, Max 5x $100, Max 20x $200)을 API 정가로 소진하도록 바뀐다. 대화형 사용(채팅, 터미널 Claude Code, Claude Cowork)은 영향 없음. 왜 중요한가: 지금까지 구독료로 무제한처럼 쓰던 무인 자동화·CI 파이프라인 사용자에게 실질적인 비용 인상이며, "구독제의 어디까지가 공정 사용인가"라는 논쟁에 불을 붙였다. [Zed Blog](https://zed.dev/blog/anthropic-subscription-changes) · [ClaudeDevs 발표](https://twitter.com/ClaudeDevs/status/2054610152817619388)
- [ ] **Claude Code 주간 사용량 한도, 7/13까지 50% 증량 — "채찍과 당근"을 같은 날 발표** — Pro·Max·Team·시트 기반 Enterprise 사용자 전체에 별도 신청 없이 즉시 적용됐다. 5/6 시간당 한도를 2배로 늘린 데 이은 5주 연속 세 번째 용량 조정으로, SpaceX와 맺은 데이터센터 계약(22만여 개 GPU 규모 Colossus 1)이 그 배경으로 지목된다. 왜 중요한가: 같은 주에 비대화형 사용은 유료화하고 대화형 사용 한도는 늘리는 상반된 신호를 함께 낸 것으로, Anthropic이 어떤 사용 패턴을 유도하려는지 보여준다. ## AX 시사점
오늘은 Anthropic이 "누구에게 무엇을 얼마에 파는가"를 한꺼번에 재정의한 날입니다. 소상공인에게는 완제품 자동화 패키지를 무료 수준으로 열어주면서, 동시에 무인 자동화·CI 사용자에게는 비용을 올리고, 대화형 사용자에게는 한도를 늘려주는 세 방향 전략이 동시에 나왔습니다. 기업이 Claude Code나 Agent SDK로 무인 파이프라인을 이미 운영 중이라면 6/15 요금 변경이 실제 비용에 미치는 영향을 지금 계산해둬야 하고, Claude Design 사례처럼 "구독을 끊으면 산출물에 접근할 수 없는" 벤더 종속 리스크도 계약·백업 정책에 반영해야 합니다.
