# AI Radar 데일리 — 2026-06-26

## 오늘의 헤드라인
OpenAI가 최강 모델 GPT-5.6 Sol을 공개했지만, 미국 정부가 승인한 "신뢰 파트너"에게만 먼저
푼다는 초유의 조건이 붙었다. 같은 날 미국 정부는 반대로 Anthropic의 Mythos 모델을 일부
기업에 한해 수출 허용으로 돌렸다 — AI 모델이 이제 무기급 수출통제 대상처럼 다뤄지는 하루였다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [x] **AgentKits — 프롬프트 몇 줄이 아니라 "진짜 돌아가는" AI 에이전트 설계도 60종 무료 공개** — 실무에 바로 쓸 수 있는 에이전트 아키텍처·프롬프트·도구·워크플로우를 담은 청사진 60개가 무료로 공개됐다. [Hacker News](https://news.ycombinator.com/item?id=48692101) · [agent-kits.com](https://www.agent-kits.com/)
    - **도구**: Claude, OpenAI, LangGraph, n8n 등 어디에든 이식 가능 (특정 벤더 종속 없음)
    - **자동화한 업무**: 30개 업무 카테고리 — 예) 권한 요청 처리(역할 정책·직무분리 확인 후 저위험 요청은 자동 승인, 고위험은 에스컬레이션), 영업 리서치(회사 정보·기술스택·최근 이슈를 인용과 함께 정리한 브리핑 작성, 데이터 없으면 지어내지 않고 표시)
    - **방법**: 각 청사진은 "설계 읽기 → 프롬프트 복사 → 키트 다운로드"의 3단계로 바로 적용 가능하게 구성. 휴먼인더루프 승인, 위험도(Trust Level) 표시, 감사 가능한 거버넌스 구조를 공통 템플릿으로 내장.
    - **포인트**: 로그인 없이 무료 공개돼 진입장벽이 낮다. "권한·에스컬레이션 설계가 기본 내장된 템플릿"이라는 점이 실무 재현 시 특히 유용 — AX 교육 자료·해커톤 스타터로 바로 활용 가능.
- [x] **터미널 코딩 에이전트 4종 실전 비교 — Claude Code, goose, OpenCode, Pi** — "이제 모델 성능은 다 비슷해졌고, 어떤 껍데기(하니스)를 쓰느냐가 관건"이라는 관점의 실전 비교 가이드가 공개됐다. [원문](https://outofcontext.dev/blog/goose-claude-code-opencode-pi/)
    - **도구**: Claude Code(Anthropic 종속형) / goose(Linux Foundation, 15개+ 프로바이더) / OpenCode(오픈소스, 75개+ 모델) / Pi(TypeScript 확장형, 20개+ 프로바이더)
    - **자동화한 업무**: 코딩 작업 자동화를 위한 도구 선택 — 팀 성향(벤더 종속 회피, 언어서버 진단 활용, 최소 오버헤드 등)에 따라 권장 도구가 달라짐
    - **방법**: goose는 "포터블 YAML 워크플로우 템플릿"으로 반복 작업을 팀 간 공유·자동화하는 것이 특징. OpenCode는 LSP 진단 통합, Pi는 TypeScript 확장으로 완전한 소유권을 강조.
    - **포인트**: "구독형 에이전트는 자율 루프를 오래 돌리면 비쌀 수 있고, API 직접 결제형은 작업당 비용을 미리 계산해야 저렴하다"는 비용 조언이 실무에 바로 적용 가능. 도구 선택 강의 소재로 유용.

[OpenAI](https://openai.com/index/previewing-gpt-5-6-sol/) · [Washington Post](https://www.washingtonpost.com/technology/2026/06/26/openai-says-us-government-will-vet-users-its-latest-ai-model/)
- [ ] **미국 정부, Anthropic Mythos 모델 일부 기업에 수출 허용으로 선회** — 지난 6월 12일 상무부의 긴급 수출통제로 전면 차단됐던 Anthropic의 Mythos(5) 모델이 "신뢰할 수 있는" 일부 미국 기업에 한해 다시 풀렸다. GPT-5.6 통제와 같은 날 나온 결정이라 "AI 모델 = 전략자산"이라는 미국 정부의 정책 방향이 뚜렷해졌다는 평가다. [Reuters](https://www.reuters.com/technology/us-releases-anthropic-model-mythos-some-us-companies-semafor-reports-2026-06-26/) · [CNBC](https://www.cnbc.com/2026/06/26/us-government-anthropic-claude-mythos5-ai.html)
- [ ] **Anthropic 이코노믹 인덱스 보고서 — "사람들은 아침 7시에 뉴스를, 저녁 6시엔 요리법을 묻는다"** — Claude 대화 패턴을 분석한 보고서에 따르면 대화의 93%가 눈에 띄는 결과물(설명·문서·가이드 등)을 만들어내고, 마케팅 매니저급 업무는 편집자급 업무보다 약 2.5배 많은 연산을 쓴다. 응답자 3분의 1 이상이 "12개월 내 업무 대부분을 AI가 처리할 것"이라 기대했고, 흥미롭게도 AI에 업무를 가장 많이 위임하는 사람일수록 자기 고용 안정성에 대해 더 낙관적이었다. [Anthropic](https://www.anthropic.com/research/economic-index-june-2026-report)
- [ ] **Claude Code 40만 세션 분석 — "코딩 실력보다 그 일에 대한 전문성이 성공을 가른다"** — 2025년 10월~2026년 4월 약 40만 건의 Claude Code 세션을 분석한 결과, 사용자가 기획의 70%를, Claude가 실행의 80%를 담당하는 분업 구조가 확인됐다. 회계사가 정산 규칙을, 변호사가 계약 요건을 알듯 "그 일을 잘 아는 사람"이 개발자와 비슷한 성공률을 보였고, 초보자는 15%, 숙련자는 28~33%의 성공률을 기록했다. [Anthropic](https://www.anthropic.com/research/claude-code-expertise)
