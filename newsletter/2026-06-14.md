- [x] **"The Engineer" — GitHub 이슈부터 병합된 PR까지 통째로 자동화하는 오케스트레이션 레이어** — Claude Code·OpenCode 같은 AI 코딩 CLI를 감싸 엔지니어링 생애주기 전체를 자동화하는 오픈소스 프로젝트. [GitHub](https://github.com/FarzamMohammadi/the-engineer)
    - **도구**: Claude Code, OpenCode 등 AI 코딩 CLI + Git worktree + SQLite 감사 로그
    - **자동화한 업무**: GitHub 이슈 접수 → 요구사항 정리 → 코드/웹 조사 → 구현 계획 → 코드 작성 → 자체 리뷰 → PR 생성·병합까지 6단계 파이프라인
    - **방법**: 작업마다 별도 git worktree를 배정해 동시 실행 시 충돌을 막고, 메인 저장소는 보호한다. 비용 상한선과 "주요 결정에서 사용자 승인 요청"이라는 자율성 정책으로 안전장치를 두며, 모든 작업을 ULID로 발행해 SQLite에 기록해 완전한 감사 추적을 남긴다. 코어가 프로토콜만 정의하고 플러그인이 구현하는 구조라 GitHub↔GitLab, Claude Code↔다른 에이전트로 쉽게 전환할 수 있다.
    - **포인트**: 감사 추적·승인 정책·워크트리 격리를 갖춘 비교적 성숙한 설계로, 기업 개발팀의 "에이전트 거버넌스" 강의 소재로 적합하다. 재현 난이도는 중간(플러그인 설정 필요).
