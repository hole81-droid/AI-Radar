# AI Radar 데일리 — 2026-06-12

## 오늘의 헤드라인
미국 정부가 국가안보를 이유로 Anthropic의 최상위 모델 Fable 5·Mythos 5의 해외 접근을 전면 차단하라고 지시했다 —
이후 일주일 넘게 이어질 대형 사태의 시작이다.
한편 개발자 커뮤니티에서는 Claude와 Codex를 역할 분담시켜 협업시키는 오케스트레이션 도구가 화제를 모았다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [x] **/architect — Claude가 설계·리뷰하고 Codex가 구현하는 "자율 소프트웨어 팩토리"** — 오케스트레이터 한 개, 전략가 에이전트, 빌더 에이전트를 조합해 이슈 처리부터 병합까지 자동화하는 오픈소스 도구. [GitHub](https://github.com/DanMcInerney/architect-loop)
    - **도구**: Claude(Fable, 전략가/리뷰어 역할) + Codex(빌더, 구현 담당)
    - **자동화한 업무**: 소프트웨어 이슈 단위의 설계→구현→검증→병합 파이프라인
    - **방법**: 오케스트레이터가 저장소 접근·에이전트 파견·최종 병합 권한을 쥐고, 각 빌더는 격리된 git worktree에서 정확히 하나의 이슈만 처리. 실행 전 "고정된 체크리스트"를 걸어두고, 에이전트는 판정 없이 증거만 수집하며 최종 병합 여부는 포스트플라이트 단계에서 결정한다.
    - **포인트**: "대규모 토큰 절감"을 주장하지만 구체적 절감률은 공개하지 않아 [추정] 성격이 강하다. 전략가/빌더 역할 분리와 워크트리 격리는 멀티 에이전트 개발 파이프라인을 가르칠 때 참고할 만한 구조다.
