# AI Radar 데일리 — 2026-08-26

## 오늘의 헤드라인
Anthropic의 최상위 모델 Fable 5가 벤치마크 1위를 지키면서도, 값이 절반인 GPT-5.6 Sol에
기업 지출 점유율을 내주고 있다는 FT 보도가 후속 수치와 함께 다시 화제(HN 805점)가 됐다. MIT와
Laude Institute는 요청 없이도 스스로 생각을 이어가는 "상시 가동형" 오픈소스 에이전트
하네스 Headlong을 실패 사례까지 투명하게 공개하며 내놨다. 커뮤니티에서는 "세션마다 재주입되는
코딩 스타일 가이드 파일(agent.md)"이 HN 프론트페이지 상위(413점)를 차지했고, Codex를
AWS Bedrock 경유로 쓰다 캐싱 설정 누락으로 비용이 치솟은 사례도 눈길을 끌었다.

## 업무 적용 Case
- [x] **agent.md — 세션마다 재주입되는 코딩 스타일 가이드 파일** — 코딩 에이전트 세션을
  새로 시작할 때마다 스타일·아키텍처 원칙을 반복 설명하지 않도록, `agent.md` 파일 하나를
  프롬프트에 자동 주입하는 개인 워크플로우. [출처](https://fabiensanglard.net/agent.md/index.html)
    - **도구**: Claude Code(VS Code 플러그인)·Antigravity — `claude.md`/`gemini.md`를
      `agent.md`로 심링크해 여러 도구에서 공유 가능
    - **자동화한 업무**: 코딩 에이전트의 스타일·구조·소통 방식을 세션 간 일관되게 유지
    - **방법**: 프로젝트 루트에 규칙을 적은 `agent.md`를 두고 세션 시작 시 자동 로드,
      기능 단위로 세션을 새로 열어 컨텍스트를 관리하며 "Reload agent.md"로 재주입 요청,
      가이드 자체도 에이전트에게 직접 갱신시켜 함께 진화시키는 구조
    - **포인트**: 이 위키가 쓰는 CLAUDE.md 컨벤션과 본질적으로 같은 패턴을 개인 개발자가
      재발명해 정리한 사례라 강의 도입부 설명에 유용하다. 다만 저자 스스로 "정량 수치는
      없다, 여전히 검증이 필요하다"고 밝힌 일화(anecdotal) 수준이라 효과를 과장하지 말 것.

## 빅 뉴스
- [x] **Anthropic, 가격 경쟁 압박 데이터 추가 확인 — Fable 5는 2배 비싸도 기업지출 11%뿐** — 어제(8/23~25) 화제였던 FT의 "Anthropic 최상위 모델이 저가 도구에 밀린다" 보도가 HN에서 805점으로 재조명되며 세부 수치가 추가로 확인됐다. Fable 5는 GPT-5.6 Sol의 약 2배 가격($10/백만 토큰)인데 기업 LLM 지출의 11%만 차지하고, OpenAI는 8/21 Sol 가격을 20%+ 인하해 Opus 5보다 저렴해졌다. Anthropic 평균 결제단가도 7월 중순 이후 약 25% 하락했다 — 앞서 8/10 Sonnet 5 가격 인상 계획을 철회하고 도입가를 영구화한 결정과 같은 방향이다. [출처](https://simonwillison.net/2026/Aug/23/anthropics-best-ai-model-struggles-to-attract-users-as-cheaper-t/)
- [x] **MIT·Laude Institute, "상시 가동형" 오픈소스 에이전트 하네스 Headlong 공개** — Claude Code·Codex처럼 요청을 받아야 움직이는 방식과 달리, 요청 없이도 스스로 사고를 이어가다 필요할 때만 사람을 부르는 에이전트 구조다. 시간당 $1~2 비용, 에이전트의 자기 서비스 중단 3회, 단일 사고 스트림의 프라이버시 격리 부재 등 실패 사례를 숨기지 않고 공개한 점이 눈에 띈다. [출처](https://theaxlabs.com/blog/headlong-persistent-agent-microharness)
- [x] **Google, "Ask Gemini in Chat" 오늘부터 순차 출시** — 8/19 예고했던 대로 Google Chat 안에서 Gmail·Drive·Calendar를 넘나들며 검색·초안 작성·일정 관리를 처리하는 기능이 2026-08-26부터 최대 15일에 걸쳐 순차 출시된다. 10월 1일까지는 사용량 한도를 높인 프로모션 기간이다. [출처](https://workspaceupdates.googleblog.com/2026/08/ask-gemini-in-chat.html)

## AX 시사점
오늘 가장 눈에 띄는 신호는 가격 경쟁이 숫자로 계속 확인되고 있다는 점이다 — 최상위 모델
가격이 2배 차이 나는데 기업 지출 점유율은 오히려 밀리고, 벤더들이 가격을 내리거나 인상
계획을 철회하는 국면이다. 사내 AI 도입 예산을 짤 때 "최신 최상위 모델 고정 계약"보다
모델 라우팅(업무 난이도별 저가/고가 모델 자동 배분) 구조를 열어두는 편이 유리해 보인다.
동시에 Codex-Bedrock 캐싱 버그 사례는 벤더 API를 직접 연동할 때 캐싱·과금 설정을 사전에
검증하지 않으면 비용이 순식간에 몇 배로 뛸 수 있다는 경고다. Headlong처럼 "상시 가동형"
에이전트가 등장하는 흐름도 지켜볼 만하다 — 자율성이 늘어날수록 비용·오작동·정보 격리
리스크를 도입 전에 설계해둬야 한다는 교훈을 실패 사례로 미리 보여주고 있다.
