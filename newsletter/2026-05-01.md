## 오늘의 헤드라인
Claude Code 플러그인 생태계에서 "Wiki Builder"라는 LLM 지식베이스 자동 구축 스킬이 등장했습니다.
미 국방부(Pentagon)가 7개 빅테크와 AI 도입 계약을 맺으면서 Anthropic만 제외돼 워싱턴 정가에 파장이 일었습니다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [ ] **Wiki Builder — Claude Code로 LLM 지식베이스(위키)를 자동으로 짜고 유지보수하는 스킬** — dair.ai Academy가 공개한 Claude Code 플러그인으로, "start a new wiki on agent memory using the research flavor" 같은 한 문장 명령으로 위키 폴더 구조·설정 파일·프롬프트 템플릿을 자동 배치합니다. [dair.ai Academy](https://academy.dair.ai/blog/wiki-builder-claude-code-plugin)
    - **도구**: Claude Code (플러그인/스킬)
    - **자동화한 업무**: 지식베이스 구축의 전체 루프 — raw 자료 저장 → 에이전트가 구조화된 위키 페이지로 컴파일 → 질문에 답하며 위키에 자동 저장 → 얇은 페이지·누락 링크 등을 정기적으로 점검하는 유지보수까지.
    - **방법**: 스캐폴딩 스크립트(폴더 레이아웃 생성) + 프롬프트 템플릿(색인·페이지·개념 컴파일용) + SKILL.md(에이전트에게 워크플로우를 가르침) 3요소 구성. 벡터DB 없이 순수 마크다운 기반.
    - **포인트**: 이 저장소(AI Radar) 자체가 이미 수행하고 있는 "LLM이 관리하는 위키" 패턴과 정확히 같은 발상입니다. 강의 소재로 바로 쓸 수 있고, AX 관점에서는 "사내 지식관리를 에이전트가 스스로 유지보수하게 하는 사례"로 제시할 수 있습니다.
