# AI Radar 데일리 — 2026-06-17

## 오늘의 헤드라인
Anthropic 직원들이 트럼프 행정부가 자신들을 "타겟팅"하고 있다고 공개 비판했고, OpenAI의 재무 부실 폭로는 더 커졌다.
그 사이 소재과학 스타트업 Ångstrom은 Claude Code로 10만 개의 GPU 실험을 무인 운영해 Meta의 모델을 넘어서는
성과를 냈다고 밝혀 눈길을 끌었다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [x] **Ångstrom, Claude Code로 10만 개 GPU 실험을 무인 운영해 소재 AI 모델 성능 경신** — 소재과학 스타트업이 연구자와 Claude Code를 결합한 실험 자동화 루프로 대규모 계산 실험을 돌린 사례. [사례 연구](https://anycloud.sh/blog/angstrom-case-study/)
    - **도구**: Claude Code + 자체 `anycloud` CLI(멀티클라우드 스팟 GPU 오케스트레이션)
    - **자동화한 업무**: 연구자가 논의한 계산 실험을 GPU 작업으로 배치 제출·상태 모니터링·결과 다운로드·플롯/요약 생성까지 자동 처리
    - **방법**: Claude Code가 연구진이 수동으로 쓰던 것과 동일한 `anycloud` CLI·클라우드 설정을 그대로 활용해 약 10만 개의 GPU 작업을 멀티클라우드 스팟 인스턴스에서 실행했다. 세션 기반 예산 제한(동시 실행 수 제한, 일일 지출 상한)으로 지출을 통제해 에이전트가 야간에도 자율적으로 실험을 관리할 수 있게 했다.
    - **포인트**: 성과는 실측치로 제시됨 — 결과물인 CSP-MACE-Å 모델이 DFT 계산 대비 1만 배 빨랐고 정확도는 DFT와 동등한 수준을 달성해 Meta의 UMA-OMC 모델을 능가했다고 밝힘. R&D 영역에서 코딩 에이전트를 "실험 운영자"로 쓰는 구체적 사례로 강의·AX 자료 가치가 높다. 예산 상한 설계는 재현 시 핵심 안전장치다.
