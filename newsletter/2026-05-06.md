# AI Radar 데일리 — 2026-05-06

> 백필 스캔 (5/1~5/8 구간 중 1일 — 이 날은 뉴스 밀도가 가장 높습니다)

## 오늘의 헤드라인
Anthropic이 샌프란시스코에서 2회차 "Code with Claude" 개발자 컨퍼런스를 열고, SpaceX와의 대형 컴퓨트 계약 및 Claude 사용량 제한 대폭 상향을 동시에 발표했습니다.
Claude가 관리하는 에이전트("Claude Managed Agents")에 "드리밍"·"아웃컴즈"·멀티에이전트 오케스트레이션 기능이 추가됐습니다.
캐나다 개인정보보호 감독기구가 OpenAI의 ChatGPT 학습 과정이 캐나다 개인정보보호법을 위반했다고 결론지었습니다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [x] **Claude Managed Agents — "드리밍"으로 자가 개선, "아웃컴즈"로 품질 평가, 멀티에이전트 오케스트레이션으로 병렬 분업** — Anthropic이 Claude가 관리하는 에이전트(Managed Agents/Cowork)에 세 가지 새 기능을 추가했습니다. [Reuters](https://www.reuters.com/business/retail-consumer/anthropic-unveils-dreaming-feature-help-its-ai-agents-self-improve-2026-05-06/) · [ArsTechnica](https://arstechnica.com/ai/2026/05/anthropics-claude-can-now-dream-sort-of/) · [ZDNet](https://www.zdnet.com/article/your-claude-agents-can-dream-now-how-anthropics-new-feature-works/)
    - **도구**: Claude (Managed Agents / Cowork)
    - **자동화한 업무**: (1) **드리밍** — 과거 세션들을 리뷰해 반복되는 실수와 팀 전체의 선호 패턴을 찾아내 에이전트가 시간이 지날수록 스스로 개선. (2) **아웃컴즈** — 성공 기준을 채점표(rubric)로 명시하면 별도 평가자 에이전트가 결과물을 검토해 부족한 부분을 지적하고 재작업을 지시 — 문서 생성 품질 8~10% 향상. (3) **멀티에이전트 오케스트레이션** — 리드 에이전트가 배포 기록·에러 로그·지표 분석 같은 하위 작업을 여러 전문 에이전트에 병렬로 분담.
    - **방법**: subagents + 장기 메모리(세션 리뷰) + 평가자-작업자 루프.
    - **포인트**: 세 기능 모두 "에이전트를 어떻게 조직처럼 운영할 것인가"에 대한 답이라, 강의에서 멀티에이전트 오케스트레이션 사례로, AX 보고서에서는 "AI 에이전트 팀의 자가 개선·품질 관리 체계" 근거로 쓰기 좋습니다.
