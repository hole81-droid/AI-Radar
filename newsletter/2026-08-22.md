## 업무 적용 Case
- [x] **개인 개발자, 셀프호스팅 샌드박스로 "프롬프트 1회→배포 완료" 에이전틱 소프트웨어 팩토리 구축** — 외부 노출 없는 자체 서버에서 Codex 에이전트가 앱 개발부터 프로덕션 배포까지 무인 완주. [출처](https://blog.jakesaunders.dev/building-an-almost-fully-self-hosted-sandboxed-agentic-software-factory/)
    - **도구**: Codex(월 £20 구독) + Hermes(OpenClaw 스타일 에이전트 프레임워크), Claude도 일부 병행
    - **자동화한 업무**: 저장소 생성→앱 개발→테스트→CI→Docker 배포→SSL 프로덕션 배포 SDLC 전 과정
    - **방법**: 승인 게이트 대신 네트워크 자체를 격리(포트포워딩 없음, VPN·DNS로만 접근)해 안전을 확보. Forgejo(Git+CI)·Coolify(PaaS)·Firecrawl(웹 접근)을 셀프호스팅해 에이전트가 도구로 호출.
    - **포인트**: "완전 자율 실행"의 리스크를 사람 승인이 아니라 인프라 격리로 통제한 설계가 핵심 — 프로토타입 단계 개인 사례라 정량 성과는 없지만 권한 설계 아이디어로 참고할 만하다.
- [x] **Claude Code 응답을 Gemini CLI로 다시 통과시켜 "버즈피드체"를 고치는 스킬 NoBuzz** — AI 응답을 다른 AI로 검수하는 크로스 모델 파이프라인. [출처](https://github.com/adnanakil/nobuzz/blob/main/README.md)
    - **도구**: Claude Code Skill `/debuzz` + Google Gemini CLI
    - **자동화한 업무**: 장황한 AI 응답을 청중별(동료/매니저/임원) 평이한 영어로 자동 번역
    - **방법**: Claude의 직전 응답을 임시 파일로 저장 → `gemini -p`로 파이프해 재작성 → 결과를 그대로 출력하는 3줄짜리 파이프라인.
    - **포인트**: 성과 수치는 없는 소규모 토이 프로젝트(스타 51개)지만, "한 AI 출력을 다른 AI로 재가공"하는 패턴 자체는 보고서 톤 자동 변환 같은 사내 업무에 응용 가능.

## AX 시사점
오늘은 Anthropic 혼자서 세 가지 다른 층위의 신뢰 구축을 동시에 진행했다 — 교육(Claude
Academy)·과학 검증(단백질 설계 외부 검증)·보안(Defender Advantage Fund)이 한 회사에서
사흘 새 나왔다는 것은, 모델 성능 경쟁만큼이나 "이 회사를 믿고 조직 안으로 들일 수 있는가"를
증명하는 활동이 벤더 전략의 핵심 축이 되고 있다는 신호다. 특히 사이버보안 확장에서 보인
"모델 직접 접근은 막고 산출물만 준다"는 설계는, AX 담당자가 사내에서 AI 보안 도구를
도입할 때 참고할 만한 권한 설계 원칙이다. 한편 커뮤니티에서는 정반대 극단의 사례도
나왔다 — 승인 게이트 없이 네트워크 격리만으로 완전 자율 배포를 시도한 개인 개발자
사례와, 벤더 API 연동 버그로 요금이 10배 뛴 사고가 같은 날 나란히 화제였다는 점은
"에이전트에게 얼마나 자유를 줄 것인가"라는 질문에 정답이 없고 여전히 케이스별 실험이
진행 중임을 보여준다.
