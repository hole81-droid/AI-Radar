# AI Radar 데일리 — 2026-05-29 (2026-05-29~05-31 통합, 백필)

> 백필 스캔: 주말을 포함한 이 3일은 소비자向 빅 뉴스가 5/29 하루에 집중되고 5/30~31은 개발자 커뮤니티의 소규모 실험·에세이 위주라 하나의 파일로 묶었습니다.

## 오늘의 헤드라인
Google의 24시간 상시 개인 AI 에이전트 "Gemini Spark"가 미국 Google AI Ultra 구독자에게 조용히 공개됐습니다.
개발자 커뮤니티에서는 Claude Code와 Codex 같은 서로 다른 코딩 에이전트를 Git만으로 실시간 소통시키는 오픈소스 실험(h5i)과, "Claude 도입 후 코드를 덜 쓰고 검증을 더 한다"는 개발자의 실사용 후기가 화제였습니다.
전체적으로 이 구간은 "에이전트에게 상시적·자율적 권한을 어떻게 나눠줄 것인가"라는 5월 하순 흐름의 연장선입니다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [x] **h5i: Claude Code와 Codex를 Git만으로 실시간 협업시키는 오픈소스 도구 "Agent Radio"** — 서버나 별도 연결 없이 Git 저장소 자체를 메신저로 써서 서로 다른 코딩 에이전트들이 작업을 조율하게 하는 실험적 프로젝트가 공개됐습니다. [Medium](https://medium.com/@Koukyosyumei/claude-code-and-codex-can-have-real-time-conversation-via-git-f95b696c1c05) · [GitHub](https://github.com/h5i-dev/h5i)
    - **도구**: h5i(AI-aware Git 확장, v0.1.5) + Claude Code + Codex
    - **자동화한 업무**: 여러 코딩 에이전트 간 작업 조율·컨텍스트 공유(멀티 에이전트 오케스트레이션)
    - **방법**: 메시지를 JSON Lines로 Git 레퍼런스(`refs/h5i/msg`)에 append하고, "i5h"라는 경량 프로토콜로 스레드(reply_to)를 유지합니다. Push는 대화 공유, Pull은 병합이 되며, 메시지가 불변·ID로 키가 잡혀 있어 서로 다른 클론이 갈라져도 충돌 없이 합쳐집니다.
    - **포인트**: 아직 개인 프로젝트 단계(성숙도: prototype)라 실전 도입 사례는 아니지만, "여러 AI 코딩 에이전트를 어떻게 조율할 것인가"라는 멀티 에이전트 설계 문제에 대한 참신한 답. Git을 다룰 줄 알면 재현 난이도는 중간 수준이라 강의 데모로 쓰기 좋습니다.
- [x] **개발자 실사용 후기: "Claude Code 도입 후 코드는 덜 쓰고, 검증·테스트는 더 한다"** — 시니어 개발자가 자신의 Claude Code 워크플로우 변화를 기록한 에세이입니다. [Henrik Warne's blog](https://henrikwarne.com/2026/05/31/with-claude-less-coding-more-testing/)
    - **도구**: Claude Code
    - **자동화한 업무**: 보일러플레이트 코드 작성, API·문법 조사, 테스트 환경 셋업
    - **방법**: 티켓 설명을 Claude에게 먼저 검증시키고 해결책을 제안받은 뒤, 생성된 코드를 리뷰하며 "왜 이렇게 구현했는지" 후속 질문을 주고받는 대화형 워크플로우로 세부를 확인합니다.
    - **포인트**: 벤치마크 수치는 없지만(evidence: anecdotal) "AI가 코드를 짜고 사람은 이해·검증·품질보증에 집중한다"는 역할 전환을 구체적으로 보여줘, 개발자 대상 강의에서 "AI 시대 개발자의 역할 변화"를 설명할 실사례로 쓰기 좋습니다.
