# AI Radar 데일리 — 2026-05-14

## 오늘의 헤드라인
OpenAI가 Codex를 ChatGPT 모바일 앱에 넣어, 폰에서도 코딩 에이전트의 진행 상황을 보고 승인·개입할 수 있게 됐습니다.
Anthropic은 자사 코딩 에이전트가 수백만 라인 규모의 대기업 코드베이스에서 실제로 어떻게 동작하는지 처음으로 상세히 공개했습니다.
마이크로소프트가 자체 재정 사정을 이유로 사내 Claude Code 라이선스를 취소하고 GitHub Copilot CLI로 이동시키기로 했다는 소식과, 한 비트코인 투자자가 Claude의 도움으로 11년간 잠겨있던 40만 달러어치 지갑을 되찾은 바이럴 사례가 함께 화제였습니다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [ ] **Anthropic, "대규모 코드베이스에서 Claude Code가 실제로 어떻게 동작하는가" 공개(HN 248점)** — [Claude 공식 블로그](https://claude.com/blog/how-claude-code-works-in-large-codebases-best-practices-and-where-to-start)
    - **도구**: Claude Code + CLAUDE.md 계층 구조 + Hooks + Skills + Plugins + MCP 서버 + Subagents
    - **자동화한 업무**: 수백만 라인 모노레포, 수십 년 된 레거시 시스템, 수십 개 저장소로 흩어진 분산 아키텍처에서 코드 탐색·수정·리팩터링 작업
    - **방법**: 코드베이스를 벡터 DB로 미리 인덱싱하지 않고, 사람 개발자처럼 디렉터리를 열고 grep으로 심볼을 찾아 참조를 따라가는 방식으로 동작. 작업 범위를 특정 하위 디렉터리로 좁혀 시작하면 불필요한 모듈 간 리팩터링을 시도하지 않고 컨텍스트도 깨끗하게 유지됨. "모델 자체보다 그 주변을 감싸는 하니스(CLAUDE.md·Hooks·Skills·Plugins·MCP·Subagents의 조합)가 실제 동작을 결정한다"는 것이 핵심 메시지.
    - **포인트**: 수천 명 규모 개발 조직이 이미 프로덕션에서 이 구조로 Claude Code를 쓰고 있다는 사실 자체가 엔터프라이즈 AX 관점에서 중요한 신호. AX 강의에서 "에이전트를 대규모 조직에 확장할 때 필요한 컨텍스트 설계"를 설명할 1차 자료로 쓰기 좋다.
