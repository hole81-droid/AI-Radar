# AI Radar 데일리 — 2026-05-16

## 오늘의 헤드라인
OpenAI가 몰타 정부와 손잡고 AI 교육 이수를 조건으로 전 국민에게 ChatGPT Plus를 1년간 무료 제공하는 국가 단위 파트너십을 발표했습니다.
Anthropic은 Claude의 컴퓨터·브라우저 사용(화면을 보고 클릭·입력하는 자동화) 기능을 안정적으로 쓰는 모범 사례를 공개했습니다.
GitHub는 Claude Code·Codex를 정면으로 겨냥한 독립 실행형 Copilot 데스크톱 앱을 예고했고, 한 개발자는 Claude Opus 4.7으로 실시간 한타바이러스 발병 현황을 자동 수집·정리하는 트래커를 만들어 눈길을 끌었습니다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [x] **Anthropic, Claude 컴퓨터·브라우저 사용(Computer Use) 모범 사례 공개** — [Claude 공식 블로그](https://claude.com/blog/best-practices-for-computer-and-browser-use-with-claude)
    - **도구**: Claude(Sonnet 4.6/Opus 4.7) + Computer Use API + 적응형 사고(adaptive thinking) + 실시간 프롬프트 주입 방어 분류기
    - **자동화한 업무**: 화면을 보고 클릭·입력해 소프트웨어를 조작하는 자동화 — 복잡한 폼 작성, 여러 애플리케이션을 넘나드는 반복 워크플로우
    - **방법**: 스크린샷을 모델의 크기 제한(최대 1568~2576픽셀)에 맞게 사전 축소하고 좌표를 실제 해상도로 환산, 지시문을 이미지보다 먼저 배치하는 등 세부 튜닝으로 정확도를 높임. 난이도에 따라 추론량을 동적으로 조절하는 "적응형 사고"와 프롬프트 주입을 자동 탐지하는 실시간 분류기를 함께 적용. 사용자가 직접 시연한 녹화를 학습 자료로 활용해 신뢰도를 높이는 방법도 제시.
    - **포인트**: "화면을 보고 대신 클릭해주는" 자동화가 데모 수준을 넘어 안정적으로 운영되려면 어떤 디테일이 필요한지 정리한 자료. 반복적인 사내 소프트웨어 조작 업무를 자동화하려는 조직에 실전 체크리스트로 활용 가능.
- [x] **개발자, Claude Opus 4.7로 한타바이러스 발병 현황 자동 수집·정리 트래커 제작** — [GitHub](https://github.com/omafas/track-hanta)
    - **도구**: Claude Opus 4.7 + 캐시된 시스템 프롬프트(비용 절감)
    - **자동화한 업무**: 2026년 다국가 한타바이러스 발병 관련 뉴스·보건당국 발표를 실시간으로 모아 정리하는 공공 보건 모니터링
    - **방법**: 여러 소스에서 관련 소식을 수집해 Claude가 자동으로 요약·정리, "AI가 작성한 것이냐"고 물으면 사실대로 밝히도록 시스템 프롬프트에 명시.
    - **포인트**: 개인 개발자가 취미 삼아 만든 소규모 사례지만, "특정 주제를 실시간으로 감시·정리하는 에이전트"라는 패턴은 뉴스 모니터링·경쟁사 동향 추적 같은 업무에도 그대로 옮길 수 있다.

[OpenAI](https://openai.com/index/malta-chatgpt-plus-partnership/) · [Engadget](https://www.engadget.com/2174473/openai-is-offering-chatgpt-plus-to-citizens-of-malta-for-a-year/)

Copilot Business·Enterprise 구독자부터 프리뷰가 시작되며 6/2 더 넓은 롤아웃이 예정돼 있다. 왜 중요한가: GitHub도 이제 "IDE 안의 도우미"가 아니라 Claude Code·Codex와 같은 층위의 독립 에이전트로 경쟁하겠다는 선언이다. ## AX 시사점
몰타 파트너십은 "AI 리터러시 교육 → 도구 무료 제공"이라는 국가 단위 확산 모델을 처음 보여줬고, 이는 기업이 사내 AX 교육을 설계할 때도 참고할 만한 순서(교육이 먼저, 도구는 그 다음)입니다. Computer Use 모범 사례와 GitHub의 독립 Copilot 앱은 "화면 자동화"와 "저장소를 넘나드는 자율 에이전트"라는 두 축에서 경쟁이 동시에 격화되고 있음을 보여주며, 기업은 이 흐름에서 어떤 축(화면 조작 자동화 vs 코드 저장소 자동화)이 자사 업무에 더 맞는지 먼저 구분해 도입 우선순위를 세워야 합니다.
