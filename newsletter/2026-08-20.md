# AI Radar 데일리 — 2026-08-20

## 오늘의 헤드라인
AX LABS가 "AI 네이티브 운영체제" 6단계 구축법을 공개했다 — 모델을 계층별로 나눠 쓰는
라우팅 전략으로 AI 비용을 80% 이상 줄였다는 창고·물류사 사례가 핵심이다. Anthropic은
Compliance API를 Cowork·Claude Code 전체로 확장해 기업 감사 대응을 강화했고, Meta는
Mac 전용 데스크톱 앱으로 화면 공유형 AI 비서 경쟁에 합류했다. 커뮤니티에서는 Anthropic의
미공개 회의록→에이전트 작업 배정 기능 "Project Parka"가 리버스엔지니어링으로 발견돼
화제였다.

## 업무 적용 Case
- [x] **모델을 계층별로 나눠 쓰면 AI 비용이 80% 준다 — "AI 네이티브 운영체제" 6단계 가이드** — 업무 매핑→툴 정리→데이터 모델→코어 구축→에이전트 배치→백그라운드 자동화 순으로 회사 전체를 재구축하는 실무 절차. [출처](https://theaxlabs.com/blog/ai-native-operating-system-6-steps) → [[theaxlabs-ai-native-operating-system-6-steps]]
    - **도구**: 특정 벤더 미명시 — 소형/중형/프론티어 3단계 모델 라우팅 아키텍처가 핵심(전체 호출의 70%는 소형 모델이 처리)
    - **자동화한 업무**: 문서 인테이크(PDF·이메일 처리)·문서 생성(제안서·보고서)·운영 질의(DB 조회)·라우팅·분류 — 전사 워크플로 전반
    - **방법**: 자동화 전에 업무 매핑·데이터 모델(단일 진실 원천)·시스템 연결부터 완성한 뒤 에이전트를 배치. 스키마 추출 시 `confidence`·`needs_review` 필드를 포함시키고 초기 2~4주는 사람이 전건 검토.
    - **포인트**: 창고·물류사 사례로 450개 프로젝트 통합·AI 비용 80%+↓·인당 주당 60시간 절감을 주장하지만 전부 AX LABS 자체 소개 수치(claimed)라 제3자 검증은 없다. "AI 도입=툴마다 버튼 추가"라는 흔한 오해를 바로잡는 AX 강의 소재로 유용.

## AX 시사점
오늘은 "비용 통제"와 "거버넌스"가 겹친 하루다. AX LABS의 모델 계층화 라우팅(80%+ 비용
절감 주장)과 Anthropic의 Compliance API 확장은 같은 방향을 가리킨다 — 에이전트 도입
초기 국면을 지나 "얼마나 저렴하게, 얼마나 통제 가능하게 굴릴 것인가"로 관심이 옮겨가고
있다는 신호다. AX 제안서에서는 "도입 여부"보다 "비용 라우팅 설계"와 "감사·통제 체계"를
같이 제시하는 편이 설득력이 높아지는 국면으로 보인다. 다만 오늘 다룬 정량 수치(AX LABS의
80% 절감, DeepSeek 스킬의 67%→82%)는 모두 자체 소개·미검증 주장이라는 점을 인용 시
반드시 명시해야 한다 — 특히 DeepSeek 스킬 사례는 커뮤니티에서 방법론 자체가 논쟁 중이다.
