# AI Radar 데일리 — 2026-08-07

> 소급 스캔: 08-05 ~ 08-07

## 오늘의 헤드라인
1. 업계 지형이 바뀌는 사흘이었다 — Google DeepMind CEO Demis Hassabis가 회장으로 물러나고, Anthropic은 Claude 전용 자체 칩팀을, Meta는 코딩 에이전트 "Muse Code"를 공개했다.
2. OpenAI가 무료 사용자에게 상위 모델 GPT-5.6 Luna를 무제한 텍스트 대화로 풀었고, Anthropic은 7.5시간 장애("올해 164번째")를 겪었다.
3. 커뮤니티에서는 "Claude Code가 메모리 파일이 아니라 대화 기록으로 스스로 개선된다"는 실측 연구, Uber의 코딩 에이전트 보안 오픈소스, "사람이 에이전트 명령 승인 시 위협의 1/3을 놓친다"는 4만 회 게임 실험이 화제였다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [x] **Claude Code, 메모리 파일이 아니라 대화 기록으로 스스로 개선된다 (실측)** — 연구자 Andrew Jesson이 시뮬레이션 비즈니스 업무(스프레드시트·CRM·이메일·티케팅)로 Claude Code(Opus 5)의 세션 중 자가개선 메커니즘을 통제 실험. [출처](https://www.andrewjesson.com/blog/claude-code-improved-through-conversation-not-memories/)
    - **도구**: Claude Code(Opus 5, xhigh effort), 메모리 파일 기록 + 대화 기록(압축 요약 포함)
    - **자동화한 업무**: 시뮬레이션 CRM·이메일·티케팅 업무 처리 정확도의 세션 내 자가개선
    - **방법**: 84회 메모리 쓰기로 지식베이스를 구축하는 조건과, 긴 대화·압축 요약만 유지하는 조건을 나눠 held-out 작업 성공률로 비교
    - **포인트**: held-out 성공률 34%→48%(+14%p), 이 중 대화 기록 기여는 +9.9%p(통계적으로 유의)인 반면 메모리 파일 단독 기여는 +1.7%p로 신뢰구간이 0을 포함(유의하지 않음) — "메모리 파일을 쓰면 똑똑해진다"는 통념을 실측으로 반박. 압축 요약이 원본 토큰의 1% 미만 비용으로 개선 효과 대부분을 보존한 점도 비용 설계에 참고할 만하다. → [[andrewjesson-claude-code-conversation-vs-memory-self-improvement]]
- [x] **Uber, Claude Code·Cursor·Codex를 노리는 공격을 실시간 탐지·차단하는 오픈소스 ADR 공개** — 코딩 에이전트 보안 관측·탐지·차단 플랫폼을 프로덕션 배포 확인, MLSys 2026 논문 게재. [출처](https://github.com/uber/ADR)
    - **도구**: Claude Code·Cursor·Codex(모니터링 대상) + 자체 관측 센서 ADR(mcp+hooks 기반)
    - **자동화한 업무**: 코딩 에이전트가 실행하는 위험 명령(자격증명 유출·시스템 파괴 등)의 실시간 탐지·차단
    - **방법**: 관측(activity 수집)→벤치마킹→위협 탐지→차단 4단계 파이프라인, 고recall 1차 트리아지 후 의심 세션만 심층 에이전틱 추론으로 재검토하는 2단 구조
    - **포인트**: 300개+ 태스크·133개 MCP 서버·17종 공격 기법 벤치마크로 검증됐고 Uber 프로덕션에 실제 배포됐다는 점에서 "생산성 도구 도입"과 "보안 거버넌스"가 동시에 필요하다는 것을 보여주는 대기업 실사례. 구체 탐지율 등 세부 성능 수치는 비공개. → [[uber-adr-claude-code-cursor-codex-security-monitoring]]
- [x] **CapForge — 로컬 자막 앱을 Claude에 MCP로 연결해 "말로 자막 편집"을 구현** — Reddit r/ClaudeAI 공개, 40+ 댓글 화제, 오픈소스 무료. [출처](https://old.reddit.com/r/ClaudeAI/comments/1vg206l/i_built_a_captioning_app_for_shortform_video_then/)
    - **도구**: Claude(MCP) + 로컬 Whisper 기반 자막 앱 CapForge
    - **자동화한 업무**: 숏폼 영상 자막(애니메이션 캡션) 생성·편집·스타일링
    - **방법**: 단어 단위 타임코드가 달린 트랜스크립트를 Claude가 MCP로 읽고, 렌더링된 프레임을 직접 확인해 스스로 수정하는 루프. 프리셋 대신 Claude가 HTML/CSS/JS로 새 캡션 스타일을 직접 작성하는 "co-author 모드"도 지원
    - **포인트**: 클라우드 업로드 없는 "로컬 우선(local-first) + MCP" 아키텍처 패턴의 좋은 예시. 커뮤니티는 "Canva보다 훨씬 빠르다"는 정성 평가가 다수였으나 정량 수치는 없음(work in progress). → [[capforge-claude-mcp-video-captioning]]

## AX 시사점
이번 사흘은 "AI 인프라 3사(Anthropic·OpenAI·Meta) 구도 완성"과 "사람의 감독 능력에 대한 냉정한 재평가"가 동시에 일어난 기간으로 요약된다. Google DeepMind의 리더십 전환, Anthropic의 자체 칩팀, Meta의 코딩 에이전트 진입은 모두 "AI 랩이 이제 연구소가 아니라 전 계층 인프라 기업으로 완전히 재편됐다"는 신호다. 동시에 커뮤니티에서는 두 개의 실측 연구가 같은 결론을 가리켰다 — 사람이 매 명령을 승인하는 보안 모델은 위협의 1/3을 놓치고(40k 게임 연구), 에이전트가 "학습"한다고 믿었던 메모리 파일은 실제 개선의 대부분을 설명하지 못했다(Andrew Jesson 연구). 두 결과 모두 "직관에 의존하지 말고 실측하라"는 이 위키의 반복 주제와 일치하며, 특히 Uber가 이미 프로덕션에 배포한 자동 탐지·차단 계층(ADR)은 "사람 승인" 모델의 한계를 조직 차원에서 어떻게 보완할지 보여주는 구체적 참고 사례다. 코딩 에이전트를 사내 확산 중인 기업이라면 생산성 지표만큼 보안 관측 계층 구축도 같은 우선순위로 검토할 시점이다.
