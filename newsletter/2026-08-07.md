# AI Radar 데일리 — 2026-08-07

## 오늘의 헤드라인
1. Anthropic이 사흘 연속(8/5~8/7) 엔터프라이즈 기능 3종(인라인 DLP·자체 인프라 실행·금융 리스크 AI)을 몰아 발표하며 기업 공략에 속도를 냈고, 동시에 Claude Code "Auto mode"를 Pro·Max·Team 기본값으로 전환해 일반 사용자의 자율성도 함께 넓혔다.

3. AMD의 AI 칩 스타트업 Taalas 인수(HN 875점)를 비롯해 하드웨어·인프라 쪽 화제가 두드러졌고, 국내 채널은 여전히 소재 부족 속에 기존 이슈(신규 LLM 벤치마크, 자체 데이터센터 구축기)를 다뤘다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [x] **Databricks, AI 코딩 에이전트 비용을 게이트웨이로 자동 관리한 사례 공개** — 개발자 개인의 절약이 아니라 인프라 레벨에서 모델 라우팅·캐싱을 자동 조정해 비용을 낮췄다. [출처](https://www.databricks.com/blog/managing-ai-coding-costs-scale)
    - **도구**: Claude Code + Codex + Cursor (Databricks 자체 Unity AI Gateway + Omnigent 메타-하네스)
    - **자동화한 업무**: 사내 AI 코딩 에이전트 운영 비용 관리 — 모델 선택·라우팅·캐싱·예산 추적을 게이트웨이가 자동 판단·집행
    - **방법**: 모든 코딩 에이전트 트래픽을 중앙 게이트웨이로 통합 → Smart Router가 품질을 유지하면서 더 저렴한 모델로 자동 라우팅 → 신규 저비용 모델(GLM 계열)을 빠르게 테스트·채택하고 비용 대비 개선 없는 모델(Opus 4.7)은 보류 → 하네스·캐싱 설정 튜닝으로 토큰 생성량 절감
    - **포인트**: 실측 수치는 "스마트 라우팅 평균비용 30%+↓", "토큰/비용 약 50%↓" 두 가지뿐이다. HN에서 화제가 된 "70% 절감" 제목은 원문에 없는 합산·과장 표현이라 위키에는 반영하지 않았다 — 주장과 실측을 구분하는 좋은 교육 사례이기도 하다. 상세: [[databricks-ai-gateway-coding-cost-management]]

## AX 시사점
이번 사흘은 "자율성 확대"와 "통제 강화"가 같은 회사에서 동시에 진행된 구간이었다. Anthropic은
Claude Code Auto mode를 기본값으로 밀면서도 같은 주에 인라인 DLP·자체 인프라 실행 기능을 내놓아,
"기본은 자율, 민감한 영역은 통제"라는 이원화 전략을 명확히 했다. 기업이 에이전틱 코딩 도구를
확산할 때 참고할 만한 정책 설계다. Millennium의 리스크 애널리스트 사례 역시 "AI가 최종 결정을
내리지 않고 사람이 검증한다"는 구조를 명시해, 규제 민감 업종의 AI 도입 신뢰 확보 방식을 보여준다.
한편 Databricks의 비용 관리 사례는 AI 도입 2단계(도입 자체는 끝났고 이제 비용을 어떻게 통제할
것인가)에 접어든 기업들에게 실질적인 참고 자료가 될 수 있다 — 단, HN 제목의 "70% 절감"처럼
과장된 2차 요약을 그대로 믿지 말고 원문 수치를 직접 확인하는 습관이 AX 담당자에게도 필요하다.
