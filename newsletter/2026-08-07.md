1. 업계 지형이 바뀐 사흘 — Google DeepMind CEO Demis Hassabis가 회장으로 물러나고 Jeff Dean 등은 "Discovery Loop"를 창업했으며, Anthropic은 자체 칩팀·엔터프라이즈 기능 3종·Auto mode 대중화까지 한꺼번에 밀어붙였고, Meta는 코딩 에이전트 "Muse Code"로 3파전에 뛰어들었다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [x] **Databricks, AI 코딩 에이전트 비용을 게이트웨이로 자동 관리한 사례 공개** — 개발자 개인의 절약이 아니라 인프라 레벨에서 모델 라우팅·캐싱을 자동 조정해 비용을 낮췄다. [출처](https://www.databricks.com/blog/managing-ai-coding-costs-scale)
    - **도구**: Claude Code + Codex + Cursor (Databricks 자체 Unity AI Gateway + Omnigent 메타-하네스)
    - **자동화한 업무**: 사내 AI 코딩 에이전트 운영 비용 관리 — 모델 선택·라우팅·캐싱·예산 추적을 게이트웨이가 자동 판단·집행
    - **방법**: 모든 코딩 에이전트 트래픽을 중앙 게이트웨이로 통합 → Smart Router가 품질을 유지하면서 더 저렴한 모델로 자동 라우팅 → 신규 저비용 모델(GLM 계열)을 빠르게 테스트·채택하고 비용 대비 개선 없는 모델(Opus 4.7)은 보류 → 하네스·캐싱 설정 튜닝으로 토큰 생성량 절감
    - **포인트**: 실측 수치는 "스마트 라우팅 평균비용 30%+↓", "토큰/비용 약 50%↓" 두 가지뿐이다. HN에서 화제가 된 "70% 절감" 제목은 원문에 없는 합산·과장 표현이라 위키에는 반영하지 않았다 — 주장과 실측을 구분하는 좋은 교육 사례이기도 하다. 상세: [[databricks-ai-gateway-coding-cost-management]]
- [x] **Claude Code, 메모리 파일이 아니라 대화 기록으로 스스로 개선된다 (실측)** — 연구자 Andrew Jesson이 시뮬레이션 비즈니스 업무(스프레드시트·CRM·이메일·티케팅)로 Claude Code(Opus 5)의 세션 중 자가개선 메커니즘을 통제 실험. [출처](https://www.andrewjesson.com/blog/claude-code-improved-through-conversation-not-memories/)
    - **도구**: Claude Code(Opus 5, xhigh effort), 메모리 파일 기록 + 대화 기록(압축 요약 포함)
    - **자동화한 업무**: 시뮬레이션 CRM·이메일·티케팅 업무 처리 정확도의 세션 내 자가개선
    - **방법**: 84회 메모리 쓰기로 지식베이스를 구축하는 조건과, 긴 대화·압축 요약만 유지하는 조건을 나눠 held-out 작업 성공률로 비교
    - **포인트**: held-out 성공률 34%→48%(+14%p), 이 중 대화 기록 기여는 +9.9%p(통계적으로 유의)인 반면 메모리 파일 단독 기여는 +1.7%p로 신뢰구간이 0을 포함(유의하지 않음) — "메모리 파일을 쓰면 똑똑해진다"는 통념을 실측으로 반박. 압축 요약이 원본 토큰의 1% 미만 비용으로 개선 효과 대부분을 보존한 점도 비용 설계에 참고할 만하다. → [[andrewjesson-claude-code-conversation-vs-memory-self-improvement]]
- [x] **Uber, Claude Code·Cursor·Codex를 노리는 공격을 실시간 탐지·차단하는 오픈소스 ADR 공개** — 코딩 에이전트 보안 관측·탐지·차단 플랫폼을 프로덕션 배포 확인, MLSys 2026 논문 게재. [출처](https://github.com/uber/ADR)

    - **자동화한 업무**: 코딩 에이전트가 실행하는 위험 명령(자격증명 유출·시스템 파괴 등)의 실시간 탐지·차단
    - **방법**: 관측(activity 수집)→벤치마킹→위협 탐지→차단 4단계 파이프라인, 고recall 1차 트리아지 후 의심 세션만 심층 에이전틱 추론으로 재검토하는 2단 구조
    - **포인트**: 300개+ 태스크·133개 MCP 서버·17종 공격 기법 벤치마크로 검증됐고 Uber 프로덕션에 실제 배포됐다는 점에서 "생산성 도구 도입"과 "보안 거버넌스"가 동시에 필요하다는 것을 보여주는 대기업 실사례. 구체 탐지율 등 세부 성능 수치는 비공개. → [[uber-adr-claude-code-cursor-codex-security-monitoring]]
- [x] **CapForge — 로컬 자막 앱을 Claude에 MCP로 연결해 "말로 자막 편집"을 구현** — Reddit r/ClaudeAI 공개, 40+ 댓글 화제, 오픈소스 무료. [출처](https://old.reddit.com/r/ClaudeAI/comments/1vg206l/i_built_a_captioning_app_for_shortform_video_then/)

    - **방법**: 단어 단위 타임코드가 달린 트랜스크립트를 Claude가 MCP로 읽고, 렌더링된 프레임을 직접 확인해 스스로 수정하는 루프. 프리셋 대신 Claude가 HTML/CSS/JS로 새 캡션 스타일을 직접 작성하는 "co-author 모드"도 지원

## AX 시사점
이번 사흘은 "AI 인프라 3사(Anthropic·OpenAI·Meta) 구도 완성"과 "자율성 확대 vs 통제 강화의 동시 진행", 그리고 "사람의 감독 능력에 대한 냉정한 재평가"가 겹친 기간이었다. Google DeepMind의 리더십 전환(Hassabis 회장 이동·Jeff Dean의 Discovery Loop 창업), Anthropic의 자체 칩팀, Meta의 코딩 에이전트 진입은 모두 "AI 랩이 연구소가 아니라 전 계층 인프라 기업으로 재편됐다"는 신호다. 동시에 Anthropic은 Claude Code Auto mode를 기본값으로 밀면서도 같은 주에 인라인 DLP·자체 인프라 실행 기능을 내놓아 "기본은 자율, 민감한 영역은 통제"라는 이원화 전략을 명확히 했고, Millennium 리스크 애널리스트 사례처럼 "AI가 최종 결정을 내리지 않고 사람이 검증한다"는 구조를 명시해 규제 민감 업종의 신뢰 확보 방식도 함께 보여줬다. 커뮤니티 쪽 실측 자료들도 같은 결론을 가리킨다 — 사람이 매 명령을 승인하는 보안 모델은 위협의 1/3을 놓치고(40k 게임 연구), 에이전트가 "학습"한다고 믿었던 메모리 파일은 실제 개선의 대부분을 설명하지 못했다(Andrew Jesson 연구), Databricks의 비용 절감 주장 중에도 원문에 없는 과장 수치가 섞여 있었다(Databricks 사례). "직관·2차 요약을 그대로 믿지 말고 실측하라"는 이 위키의 반복 주제가 이번 사흘에 특히 뚜렷했고, Uber ADR처럼 이미 프로덕션에 배포된 자동 탐지·차단 계층은 "사람 승인" 모델의 한계를 조직 차원에서 보완하는 구체적 참고 사례다. 코딩 에이전트를 사내 확산 중인 기업이라면 생산성 지표만큼 비용 관리·보안 관측 계층 구축도 같은 우선순위로 검토할 시점이다.
