# AI Radar 데일리 — 2026-09-01

## 오늘의 헤드라인
장피엠(YouTube)이 Claude Code·Codex·ChatGPT Work 겸용 오픈소스 웹 크롤링 에이전트를
무료 공개하며 나라장터·금감원·쿠팡·로그인 필요 사이트까지 실전 수집을 시연했다.
Anthropic은 Claude Code 표준 주간 사용한도를 "25% 인상"한다고 발표했지만, 동시에
프로모션이 종료되며 실제 체감은 "17% 감소"인 것으로 확인됐다. 그리고 08-26 발표된
Salesforce·Anthropic의 "Claudeforce" 파트너십(Claude 안에서 쓰는 37종 세일즈 스킬)이
지난 스캔들에서 누락된 것을 뒤늦게 확인해 오늘 소급 반영한다.

## 업무 적용 Case
- [x] **알아서 웹 데이터 긁어오는 AI 에이전트 무료 공개** — 입찰공고·채용공고·리뷰
  데이터를 수동 복사·붙여넣기 하던 업무를 자동화. [출처](https://www.youtube.com/watch?v=iJfRqfDetsI)
    - **도구**: Claude Code(또는 Codex·ChatGPT Work)에서 셋팅하는 오픈소스 에이전트
      "web-crawler"(GitHub, MIT 라이선스)
    - **자동화한 업무**: 웹사이트 데이터 수집 전 과정 — URL+수집 항목 한 줄 설명 →
      사이트 정찰 → 수집 전략 선택(정적/세션/동적/안티봇) → 수집코드 생성·실행 → 엑셀 정리
    - **방법**: 판단(어떤 수집 전략을 쓸지)은 LLM이, 실행(실제 크롤링)은 결정론적으로
      생성된 Python 코드가 맡는 코드-LLM 역할분담 구조. Node.js 기반 `agent-browser`로
      사이트 구조를 먼저 정찰한 뒤 Scrapling으로 수집한다. robots.txt 준수+속도제한,
      PII 탐지 경고, CAPTCHA/자격증명 자동처리 금지 등 안전장치 내장.
    - **포인트**: 나라장터 입찰공고 140건·금감원 PDF 107개·쿠팡 리뷰 1,000건을 실전
      시연(제작자 시연 수치, 제3자 검증은 아님). 비개발자도 GitHub clone부터 따라올 수
      있게 설명한 점, 그리고 "정찰-전략-실행"을 코드와 LLM이 나눠 맡는 하이브리드 설계가
      강의 소재로 유용. 로그인 필요·개인정보 포함 사이트 수집은 이용약관·법적 리스크
      검토가 선행돼야 한다.

## 빅 뉴스
- [x] **Claude Code 주간 사용한도, "25% 인상"인데 체감은 "17% 감소"** — Anthropic이
  Pro·Max·Team·좌석형 Enterprise의 표준 주간 사용한도를 09-14부터 25% 영구 인상한다고
  발표했다. 그런데 지금은 프로모션으로 일시 50% 증량이 적용된 상태고 이 프로모션이 같은
  날 종료된다 — 즉 원래 대비로는 +25%지만, 지금 당장 쓰는 양 대비로는 17% 줄어드는
  것이다. Anthropic 스스로도 이 점을 인정하며 "사용량을 더 잘 체감·통제하게 해줄 변화를
  준비 중"이라고 밝혔다(HN 64점). [출처](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-is-cutting-claude-codes-current-weekly-limits-by-17-percent/)
- [x] **Salesforce·Anthropic "Claudeforce" 파트너십(08-26 발표, 소급 반영)** — CRM
  화면이 아니라 Claude 안에서 바로 쓰는 37종 사전 구축 세일즈 스킬 "Salesforce in
  Claude"를 공개했다. 회의 준비·딜 헬스 리뷰·파이프라인 관리 등을 Claude에서 실시간
  매출 데이터 기반으로 처리할 수 있다. Claude는 Amazon Bedrock을 통해 Salesforce
  보안 경계(Trust Boundary) 안에서 서빙돼 데이터가 외부로 나가지 않는 구조다. 9월
  오픈 베타 예정이며, 발표 당일 Salesforce 주가가 시간외 12% 뛰었다.
  [출처](https://www.salesforce.com/news/press-releases/2026/08/26/salesforce-and-anthropic-announce-claudeforce/)

## AX 시사점
오늘 뉴스 두 건은 "벤더 발표문을 있는 그대로 믿지 말고 실제 계약·요금 구조를 뜯어봐야
한다"는 같은 교훈을 준다. Claude Code 사용한도는 "25% 인상"이라는 프레이밍과 "17%
감소"라는 체감 사이의 간극을 보여줬고, Claudeforce는 "AI가 CRM에 들어온다"는 헤드라인
아래 실제로는 데이터가 벤더 보안 경계를 벗어나지 않는 구체적 인프라 설계(Bedrock+Trust
Boundary)가 핵심이었다. 기업이 AI 벤더 파트너십·요금 변경 뉴스를 검토할 때는 발표
프레이밍이 아니라 "데이터가 어디 머무는가", "지금 대비 실질 변화량이 얼마인가"를
직접 계산해보는 습관이 필요하다. 한편 장피엠의 웹 크롤링 에이전트 사례는 비개발자
직군(총무·구매·마케팅)이 오픈소스 하나로 반복적 웹 모니터링 업무를 자동화할 수 있다는
것을 보여줘, 사내 AX 교육에서 "무료로 바로 시도해볼 수 있는 사례"로 쓰기 좋다.
