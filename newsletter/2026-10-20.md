# AI Radar 데일리 — 2026-10-20

## 오늘의 헤드라인
1. 해커 1명이 AI 에이전트 군단(Claude Code 하네스 추정)으로 John Deere·SharkNinja 등 100개 이상 기업을 침해 — 작업당 $5.
2. Delta·Yelp·JPMorgan Chase 등 주요 사이트들이 AI 에이전트 접근을 차단하기 시작, 한편 Accenture는 직원 1인당 Claude 지출을 월 $29로 제한.
3. tmux 세션 관리·Skill 역설계(REA)·MCP 회의녹음 앱 등 Claude Code 실전 활용법 3건, 그리고 100건 이상 기업 롤아웃 경험자의 비용 관리 체크리스트.

## 업무 적용 Case
- [x] **tmux로 Claude Code 멀티 에이전트 세션 운영하기** — 여러 저장소의 에이전트를 한 화면에서 병렬로 띄우고 원격 조작. [출처](https://crystl.dev/guides/tmux-for-ai-agents/)
    - **도구**: Claude Code + tmux
    - **자동화한 업무**: 여러 저장소에서 동시에 돌아가는 코딩 에이전트 세션 관리·원격 제어
    - **방법**: 저장소당 tmux 세션 하나(세션명=저장소명), `send-keys`로 명령 주입, `capture-pane`으로 상태 확인, `pipe-pane`으로 출력 로깅. SSH가 끊겨도 서버에서 세션이 계속 돈다.
    - **포인트**: 에이전트별 "대기 중" 상태 표시가 안 되고 재부팅 시 세션이 사라지는 게 한계 — Claude Managed Agents 같은 벤더 오케스트레이션과 비교 교육 소재로 적합. [[crystl-tmux-claude-code-multi-session]]

- [x] **"스킬을 쓰지 말고 역설계하라" — 베스트·워스트 사례 12건으로 Claude Skill 재구축** — Ben AI가 공개한 Reverse Engineer Anything(REA) 기법. [출처](https://www.youtube.com/watch?v=57FpQnLTEBY)
    - **도구**: Claude (Skills)
    - **자동화한 업무**: 반복 콘텐츠 작업(뉴스레터)의 Skill 제작
    - **방법**: 과거 결과물 중 잘된 것 6편·안 된 것 6편을 Claude에 보여주고 차이를 추론시킨 뒤, 추론된 패턴을 Skill 지시문으로 저장하는 3단계. 글로 지시문을 쓰는 과정을 건너뛴다.
    - **포인트**: 예시 품질이 애매하면 통하지 않는다고 저자가 직접 밝힘. "업무 지시를 글로 못 써도 예시만 모아두면 된다"는 점에서 비개발자 Skill 교육에 특히 유용. [[benai-claude-skills-reverse-engineer-rea]]

- [x] **Claude Code로 만든 Mac 회의녹음 앱 — MCP로 Claude에서 바로 검색** — 오픈소스 "Overheard", 로컬 우선 설계. [출처](https://github.com/anonbeat1/overheard)
    - **도구**: Claude Code(개발) + MCP(연동)
    - **자동화한 업무**: 회의 녹음·화자구분 전사·요약 후 Claude Code/Desktop에서 검색·채팅
    - **방법**: Meet/Teams/Slack 사용 감지 시 자동 녹음, 로컬(MLX)·클라우드(ElevenLabs) 전사 선택, 자체 MCP 서버로 전사 데이터를 Claude에 노출. 모든 데이터는 `~/Meetings`에 로컬 저장.
    - **포인트**: 벤더 SaaS 구독 없이 사내 회의록 도구를 직접 만드는 대안 경로. 민감 대화 내용의 로컬 처리가 기업 도입 시 장점. [[overheard-claude-code-meeting-recorder-mcp]]

- [x] **해커 1명, AI 에이전트 군단으로 100개 이상 기업 침해** — 보안업체 Norforge가 오픈소스 플랫폼 Cairn의 노출된 작업 로그를 분석해, John Deere·SharkNinja·Cummins 등을 침해한 사건을 포착했다. 모든 작업이 `claudecode_deepseek-v4.1-flash`라는 워커로 실행됐는데, Claude Code 하네스에 DeepSeek 모델을 끼운 구성으로 추정된다. 작업당 평균 $5, 성공 1건당 약 $50 — 기존 수동 침투테스트보다 훨씬 저렴한 공격 비용이 가능함을 보여준다. [출처](https://thenextweb.com/news/ai-agents-hacker-cairn-100-sites-deere-norforge)
- [x] **웹사이트들이 AI 에이전트에 문을 닫기 시작했다** — Delta는 에이전트의 항공권 예약을 막고, JPMorgan Chase·Charles Schwab은 계정 접근을 차단하며, Yelp는 데이터 이용료를 내는 에이전트만 허용한다. OpenAI·Meta·xAI가 "에이전트가 대신 다 해준다"를 내세우지만, 항공·금융·쇼핑처럼 실제 돈이 걸린 영역일수록 먼저 거부당하고 있다. [출처](https://www.theverge.com/ai-artificial-intelligence/1013195/ai-agents-blocked-web)
- [x] **Accenture, 직원 1인당 Claude 지출을 월 $29로 제한** — Anthropic 사상 최대 규모의 Claude Code 배포 고객(직원 약 3만 명 교육)에서 일부 직원이 월 $500~$1,000를 쓰던 게 적발돼 10월 1일부로 중앙 지원 예산이 깎였다. "전원 무제한 배포"로 시작한 롤아웃이 1년 안에 비용 통제 단계로 넘어간 사례. [출처](https://www.404media.co/accenture-tells-employees-they-can-now-spend-only-29-on-claude-per-month/)
- [x] **MIT Sloan: 데이터 과학 프로젝트의 60~85%가 실패한다** — 소매업 사례를 들어 "수요 예측 모델은 있는데 재고를 어떻게 배치할지는 여전히 모른다"는 문제를 짚고, 데이터 모델링보다 "경영진이 실제로 내려야 하는 결정"에 초점을 맞춘 의사결정 과학(Decision Science)으로 전환을 제안한다. [출처](https://sloanreview.mit.edu/article/why-data-modeling-is-not-enough/)

- [x] **벤더 발표 자동화 사례 3,362건 분석: "AI"라고 주장하는 건 13%뿐** — r/AI_Agents에 한 사용자가 수 주간 모은 "이름 있는 기업+구체 성과"가 명시된 벤더 사례 3,362건을 분류한 결과, AI(ML·생성형·에이전트 포함)를 주장하는 건 436건(13%), 그중 에이전트는 18건, 고객지원 에이전트는 7건뿐이었다고 한다. 나머지 대다수는 시스템 연동·ERP·일정관리 같은 "평범한 소프트웨어"였다는 주장. 1인이 비공개로 집계한 데이터라 방법론 검증은 안 됐지만, "에이전트 과장과 실제 도입률 간극"을 짚는 수치로 화제가 됐다.
