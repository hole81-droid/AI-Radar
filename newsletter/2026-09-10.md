## 업무 적용 Case
- [x] **Cognition, Devin 에이전트로 35년 묵은 RSA-260 암호 인수분해 기록 경신** (09-09) — 프롬프트 하나 + 오버나이트 무인 실행으로 시작해 3주간 최대 18개 동시 세션으로 확장, 기존 최고기록 대비 비용 약 10배 절감. [Cognition 블로그](https://cognition.com/blog/factoring-rsa-260) · 상세: [[cognition-devin-rsa-260-factoring]]
    - **도구**: Devin(Cognition의 코딩 에이전트) + Modal GPU 클라우드 API
    - **자동화한 업무**: 기존 CPU 기반 정수 인수분해 소프트웨어(CADO-NFS)의 핵심 연산을 GPU용으로 재작성, 862비트 RSA-260 인수분해 실행
    - **방법**: "CPU 시버를 대체할 GPU 버전을 만들어달라"는 짧은 프롬프트와 테스트 GPU 1개 API 키만 주고 무인 실행 → 다음 날 작동하는 프로토타입 확보 → 이후 3주간 최대 18개 Devin 세션을 동시에 운영해 나머지 코드베이스 재작성 → 실제 RSA-260에 적용해 인수분해 성공
    - **포인트**: 비용($400K, 4,900 GPU-day)·성과(기존 대비 약 10배 저렴)가 모두 실측 공개된 드문 사례. "프롬프트 하나로 시작해 다중 세션 오케스트레이션으로 확장"하는 전형적인 에이전트 도입 성숙도 곡선을 보여준다. 다만 상용 서비스가 아니라 연구·기록 경신 프로젝트라는 점은 감안할 것.
