# AI Radar 데일리 — 2026-05-15

## 오늘의 헤드라인
결제 데이터 업체 Ramp의 지출 데이터 분석에서 Anthropic이 기업 AI 도입률 34.4%로 OpenAI(32.3%)를 처음으로 앞섰다는 결과가 나왔습니다 — 1년 만에 9%에서 34.4%로 4배 성장한 배경은 Claude Code였습니다.
OpenAI는 ChatGPT를 Plaid와 연동해 은행 계좌를 직접 들여다보고 개인 재무 조언을 해주는 기능을 내놓았습니다.
1Password는 수백만 라인 규모 Go 모놀리식 코드베이스를 AI 에이전트로 분해한 실전 경험을, Claude Code 제품 총괄은 사용량 한도·투명성 전략을 각각 공개했습니다.

## 에이전트 구축 · 업무 자동화 ★최우선
- [ ] **1Password, AI 에이전트로 수백만 라인 Go 모놀리식 코드 분해 — 실전에서 통한 것과 깨진 것** — [1Password 블로그](https://1password.com/blog/what-we-learned-using-ai-agents-to-refactor-a-monolith)
    - **도구**: 자체 구축한 에이전틱 툴체인(코드 분석 + 서비스 추출 순서 결정 + 결정론적 실행 도구 조합)
    - **자동화한 업무**: 대규모 모놀리식 서비스를 더 작은 서비스로 분해(service extraction)하는 리팩터링 작업
    - **방법**: 에이전트가 수백만 라인 코드를 분석해 "어떤 순서로 서비스를 떼어내야 하는지" 추출 순서를 제시. 작업 범위가 명확히 정의되고 경계가 있을 때는 에이전트가 빠르고 정확했지만, 명세 밖 상황(예: UUID 컬럼 백필을 신규 행 삽입 코드 갱신보다 먼저 실행해 데이터를 조용히 손실시키는 순서·불변조건 문제)을 만나면 스스로 해결하려 하지 않고 표면화하도록 설계함.
    - **포인트**: 전체적으로 20~30% 개선을 봤지만 "면밀한 조정과 리뷰의 필요성을 대체하지는 못했다"는 결론. 강의·AX 자료에서 "에이전트에게 무엇을 맡기고 무엇을 사람이 계속 봐야 하는가"를 구체적 수치로 보여주는 드문 사례.

- [ ] **Ramp 지수: Anthropic, 기업 AI 지출 점유율에서 OpenAI 첫 추월(34.4% vs 32.3%)** — 5만여 개 미국 기업의 실제 결제 데이터를 추적하는 Ramp AI Index 기준. 1년 전(2025년 5월) 9%였던 Anthropic의 기업 도입률이 34.4%로 4배 뛴 반면 OpenAI는 같은 기간 0.3%포인트 성장에 그쳤다. 금융·기술·전문서비스 등 고도입 업종에서 Anthropic이 앞서는데, 성장의 핵심 동력은 Claude Code다. 왜 중요한가: 소비자 인지도와 별개로 "기업이 실제로 돈을 쓰는" 지표에서 처음 벌어진 역전이라는 점에서 신뢰도가 높다. [VentureBeat](https://venturebeat.com/technology/anthropic-finally-beat-openai-in-business-ai-adoption-but-3-big-threats-could-erase-its-lead)

[OpenAI](https://openai.com/index/personal-finance-chatgpt/) · [The Verge](https://www.theverge.com/ai-artificial-intelligence/931122/openai-chatgpt-financial-accounts-plaid-connection)
- [ ] **Claude Code 제품 총괄, 사용량 한도·"린 하니스" 전략을 언론에 처음 공개** — Ars Technica 인터뷰에서 Anthropic이 무제한 접근보다 "제한된 접근 + 투명한 설명"을 택한 이유를 설명했다. 답변 형식을 짧은 diff·타겟팅된 설명으로 유도하는 내부 제어 계층("린 하니스")이 특정 작업에서 속도를 약 18% 높였다고 밝혔다. 왜 중요한가: 5/13 발표된 한도 조정·요금 변경의 배경 철학을 제품 책임자가 직접 설명한 자료다.
