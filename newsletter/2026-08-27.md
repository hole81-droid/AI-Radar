# AI Radar 데일리 — 2026-08-27

## 오늘의 헤드라인
Anthropic이 IPO 투자자에게 "잠재 매출 $30조"라는, SpaceX 상장 전 추정치(28.5조)를 웃도는
시장 규모를 제시할 예정이라는 WSJ 보도가 나왔다. 같은 주 Claude의 메모리가 대화창(Chat)과
클라우드 작업 에이전트(Cowork) 전체로 통합돼, 어디서 말하든 같은 기억을 이어받게 됐다.
크리에이터 Ben AI는 Claude Cowork의 "화면 녹화로 스킬을 만드는" 공식 기능 활용법을 공개하며
"프롬프트 대신 시연으로 AI를 가르치는" 흐름을 이어갔다.

## 업무 적용 Case
- [x] **Ben AI — Claude Cowork "Record a Skill"로 10배 나은 스킬 만들기** — 화면 녹화 한 번으로
  반복 업무를 재사용 가능한 Claude Skill로 변환하는 공식 기능의 활용 베스트프랙티스.
  [출처](https://www.youtube.com/watch?v=zEv0lLYjUHw)
    - **도구**: Claude Cowork — 2026-07-21 출시된 공식 기능 "Record a Skill"(화면 클릭·키
      입력·음성 코멘터리를 캡처해 Claude가 스킬로 합성)
    - **자동화한 업무**: 반복 사무 업무를 텍스트 프롬프트 작성 없이 "시연 → 스킬" 형태로
      자동화 자산화
    - **방법**: Cowork 작업 화면의 `+` 메뉴에서 Record a Skill을 실행해 업무를 처음부터
      끝까지 녹화·설명하고, 4가지 베스트프랙티스에 맞춰 녹화를 구성한 뒤 Claude가 제안한
      스킬 초안을 검토·저장하는 절차를 라이브 데모로 시연
    - **포인트**: 같은 크리에이터가 5주 전(07-18) 공개한 "프롬프트로 스킬 만들기" 방법론과
      짝지어 비교 강의 소재로 쓰기 좋다. 정량 성과 수치는 없고 유료 프로그램 홍보를 겸한
      콘텐츠라는 점은 감안할 것. 비개발 인력이 코딩 없이 업무 매뉴얼을 스킬로 남길 수 있는
      저비용 진입점이라 AX 파일럿 소재로도 유효하나, 민감 정보 화면 녹화 시 유출 리스크는
      별도 점검 필요.

## 빅 뉴스
- [x] **Anthropic, IPO 투자자에게 "잠재 매출 $30조" 시장 규모 제시 예정** — WSJ 보도에 따르면
  Anthropic이 총주소가능시장(TAM) $30조 이상을 투자자에게 제시할 예정이다. SpaceX가 상장
  전 제시했던 $28.5조를 웃도는 수치이며, 최대 $100B 조달·약 $2조 밸류에이션을 목표로 하는
  것으로 알려졌다. 2분기 매출은 전분기 대비 두 배 이상인 $11.6B로 보도됐다. TAM은 "이론상
  최대 매출"이지 실제 전망치는 아니지만, 앞서 확인된 실측 연환산매출 급성장($47B→$65B,
  7월 기준)과 함께 놓고 보면 IPO를 앞둔 성장 서사 강화로 읽힌다.
  [출처](https://www.wsj.com/tech/ai/anthropic-expected-to-tell-investors-it-sees-over-30-trillion-in-potential-revenue-a611efea)
- [x] **Claude 메모리, Chat과 Cowork 전체로 통합** — 지금까지 따로 놀던 대화창 기억과
  Cowork(클라우드 작업 에이전트)의 기억이 하나로 합쳐졌다. Settings에 Memory 탭이 새로
  생겨 Claude가 기억한 내용을 항목별로 보고 수정·삭제할 수 있고, 건강·인종·종교·정치 성향
  등 민감 주제는 기본적으로 저장하지 않는다. Free·Pro·Max 전체에서 기본값으로 켜져 있다.
  [출처](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context)

## AX 시사점
오늘의 결은 "성장을 보여주는 숫자"와 "신뢰를 관리하는 디테일"이 동시에 움직였다는 점이다.
Anthropic은 TAM $30조라는 압도적인 숫자로 IPO 서사를 밀어붙이는 동시에, 메모리 통합처럼
"AI가 나를 얼마나 기억하고, 그걸 내가 어떻게 통제할 수 있는가"를 설정 화면에 노출하는
투명성 장치도 함께 내놓았다. 사내 도입 관점에서는 두 가지를 같이 봐야 한다 — 벤더의 성장
서사(TAM, 밸류에이션)에 휘둘리기보다 실제 도입 비용·리스크로 판단할 것, 그리고 메모리처럼
편의 기능이 늘어날수록 "부서 간 정보가 새어나가지 않는가"를 파일럿 단계에서 반드시 검증할
것. Ben AI의 Record a Skill 활용법은 비개발 인력의 자동화 진입장벽을 낮추는 방향이 계속
강화되고 있음을 보여주는데, 이 역시 편의성과 보안 리스크(민감 업무 화면 녹화)를 함께
검토해야 하는 사례다.
