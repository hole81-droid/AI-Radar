- [ ] **Claude Code에 다중 에이전트 관리 화면 "Agent View" 추가** — [공식 문서](https://code.claude.com/docs/en/agent-view) · [Hacker News](https://news.ycombinator.com/item?id=48159960)
    - **도구**: Claude Code `claude agents` 명령
    - **자동화한 업무**: 백그라운드에서 동시에 실행 중인 여러 Claude Code 세션(에이전트)을 하나의 화면에서 파악·관리
    - **방법**: 세션을 "입력 필요(Needs input)/작업 중(Working)/완료(Completed)"로 자동 분류해 보여주고, 개입이 필요한 세션에만 들어가 응답. 각 백그라운드 세션은 터미널이 붙어있지 않아도 계속 실행되며, 화면 하단 입력창으로 새 세션을 바로 띄울 수 있음.
    - **포인트**: "에이전트 여러 개를 동시에 굴린다"는 개념이 개인 실험 수준을 넘어 공식 기능으로 자리 잡았다는 신호. 강의에서 다중 에이전트 오케스트레이션을 설명할 때 가장 쉬운 실습 진입점으로 쓰기 좋다.
