OpenAI ChatGPT Work의 실제 채택률이 공개됐다 — 사내 직원은 98%가 쓰지만 외부 조직

## 업무 적용 Case
- [x] **Kindle 노트북 내보내기 제한 하이라이트, Claude Code 스킬로 전량 복구** — Amazon Kindle 노트북에서 "일부 하이라이트가 내보내기 제한으로 숨겨지거나 잘렸다"는 문제를 개인 개발자가 Claude Code 스킬로 해결했다. [출처](https://github.com/l3a0/claude-plugins)
    - **도구**: Claude Code Skill(`/l3a0:kindle-highlights`) + Claude Desktop "Control Chrome" 확장
    - **자동화한 업무**: Kindle 하이라이트 전량 추출 및 내보내기 차단분 복구, 위치 인용 포함 마크다운 통합
    - **방법**: (1) Chrome 제어로 노트북 페이지 DOM 스크래핑 → (2) Mac Kindle 앱의 로컬 SQLite 주석 DB에서 정확한 위치 대조 → (3) 차단된 구간은 Cloud Reader 캡처 후 Apple Vision OCR로 복구. 3단계 파이프라인을 하나의 스킬로 엮은 구조.
    - **포인트**: 실측 성과가 명확하다 — 책 4권에서 하이라이트 2,432개 추출, 차단됐던 815개(잘림 454+숨김 361) 전량 복구. "브라우저 제어 + 로컬 DB 대조 + OCR"을 조합하는 스킬 설계 패턴은 사내 레거시 시스템의 제한적 데이터 내보내기를 보완하는 아이디어로도 응용 가능. 다만 개인 4권 처리 사례 하나뿐이라 규모 확장성은 미검증.
