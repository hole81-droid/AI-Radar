# Claude Cowork 실전 사례 7가지 — 코딩 없는 사무 자동화

> **공식**: [Claude Cowork]로 [MCP 커넥터 연결 + 자연어 지시 + 브라우저 녹화 스킬화]를 활용해 [비개발자 사무 업무 7종]을 수행 → [경비 처리 월 2시간→10분, 메일 정리 30분/일 절약 (주장)]

## 무엇을 자동화했나

지피터스(GPTers) 커뮤니티가 정리한 Claude Cowork 실전 사례 모음. 게시일은 2026-02 중으로 정확한 날짜는 미확인.

| # | 업무 | 방법 | 성과 (주장) |
|---|------|------|------|
| 1 | 다운로드 폴더 정리 | "파일 종류별로 정리해줘" — 확장자·내용 기반 분류 | 수백 개 파일 몇 분 내 정렬 |
| 2 | 리서치→발표자료 원스톱 | 한 프롬프트로 조사→정리(마크다운·Excel)→슬라이드. 브랜드 가이드 제공 시 디자인 맞춤 | 3단계 통합 처리 |
| 3 | 영수증→경비 보고서 | 영수증 사진/PDF 폴더 저장 → 가맹점·날짜·금액·카테고리 자동 추출 | **월 2시간→10분** |
| 4 | 아침 브리핑 문서 | Slack·Notion·팀 대시보드를 MCP로 연결, 팀 활동·우선순위 통합 | Slack 스크롤 시간 절약 |
| 5 | 데이터 분석 리포트 | PostHog·Google Analytics 연동, "30일 DAU 트렌드 분석" — 급락 원인 추론까지 | raw 데이터 처리 시간 절약 |
| 6 | 메일 우선순위 분류 | Gmail 연동, 긴급 메일 상단 배치·뉴스레터 분류·답장 초안 | **아침 30분 절약** |
| 7 | 반복 업무 커스텀 스킬화 | 브라우저 동작 녹화→패턴 학습→자동 재현 (예: 매주 월요일 데이터 추출·정리) | 코딩 불필요 |

## 어떻게 구성했나 (아키텍처)

- **연결 계층**: 로컬 폴더 접근 + MCP 커넥터(Slack, Notion, Gmail, PostHog, Google Analytics)로 외부 서비스 연결
- **지시 계층**: 자연어 프롬프트 한 개로 다단계 업무(조사→정리→산출물) 실행
- **자산화 계층**: 반복 업무는 브라우저 동작을 녹화해 커스텀 스킬로 저장·재현. Anthropic 오픈소스 플러그인 11종(영업·법무·재무·마케팅·데이터 분석·개발)도 활용 가능
- Claude Code와의 분업: 비개발자가 Cowork로 PRD 작성 → 개발자가 [[claude-code]]로 구현하는 워크플로우 제안

## 벤치마크 데이터

## 성과와 수치

- **주장(claimed)**: 경비 보고서 월 2시간→10분, 아침 메일 정리 30분 절약, 수백 개 파일 몇 분 내 정리. 모두 커뮤니티 편집 글의 서술이며 실측 검증 자료는 없음.
- 한국어 최적화는 아직 부족 — 언어 의존도 낮은 작업(파일 정리·데이터 추출)부터 시작 권장 (원문).

## 재현 가이드

- **난이도**: 하 (코딩 불필요)
- **준비물**: Claude Pro 이상 구독, Claude Desktop 앱(또는 claude.com/cowork), 연동할 서비스 계정(Slack·Notion·Gmail 등)
- **핵심 단계**:
  1. Cowork에 작업 폴더 접근 권한 부여, 필요한 MCP 커넥터 연결
  2. 언어 의존도 낮은 업무(파일 정리·영수증 정리)부터 자연어로 지시
  3. 브리핑·리포트류는 커넥터(Slack·Analytics)를 붙여 한 프롬프트 루틴으로 확장
  4. 매주 반복되는 업무는 브라우저 녹화로 커스텀 스킬화해 자산으로 저장

## 강의·AX 활용 포인트

- **강의**: "코딩 없는 사무 자동화 7종 세트" — 난이도 순(폴더 정리→경비→브리핑→스킬화)으로 배열하면 그대로 비개발자 실습 커리큘럼이 된다.
- **AX**: 부서별 도입 우선순위 판단 자료 — 경비·메일·브리핑은 전 직군 공통 업무라 도입 효과 체감이 빠르다. 단 수치가 전부 주장 수준이므로 사내 파일럿으로 실측 후 확산하는 접근이 필요.
