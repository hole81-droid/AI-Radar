# 개인 개발자, Claude Opus 4.7로 한타바이러스 발병 현황 자동 트래커 제작

> **공식**: Claude Opus 4.7(캐시된 시스템 프롬프트)로 다중 소스 수집·요약 파이프라인을 활용해 한타바이러스 발병 뉴스·보건당국 발표 실시간 모니터링을 수행 → 개인 프로젝트로 공공 보건 트래커 자동 운영

## 무엇을 자동화했나

개인 개발자가 2026년 다국가 한타바이러스 발병 관련 뉴스·보건당국 발표를 실시간으로 모아
정리하는 공공 보건 모니터링 트래커를 Claude Opus 4.7로 제작했다.

## 어떻게 구성했나 (아키텍처)

- 여러 소스에서 관련 소식을 수집해 Claude가 자동으로 요약·정리.
- 비용 절감을 위해 캐시된 시스템 프롬프트를 활용.
- "AI가 작성한 것이냐"고 물으면 사실대로 밝히도록 시스템 프롬프트에 명시 — 투명성을
  설계 단계에서 반영.

## 벤치마크 데이터

| 항목 | 값 |
|---|---|
| 모델 | Claude Opus 4.7 |
| 비용 | 미확인 (시스템 프롬프트 캐싱으로 절감했다는 서술만 있음) |
| 권한 | 미확인 |
| 성숙도 | prototype (개인 취미 프로젝트) |

## 성과와 수치

- 정량 수치는 없음 — **일화(anecdotal)** 수준의 개인 프로젝트 소개.
- 다만 "특정 주제를 실시간으로 감시·정리하는 에이전트"라는 패턴 자체는 검증된 작동
  사례로 제시됨.

## 재현 가이드

- **난이도**: 하
- **준비물**: Claude(Opus 계열), 모니터링 대상 소스 목록, 캐시 가능한 시스템 프롬프트
- **핵심 단계**:
  1. 모니터링할 주제·소스를 명확히 정의
  2. 시스템 프롬프트를 캐싱해 반복 호출 비용을 낮춤
  3. AI 생성 콘텐츠임을 투명하게 밝히는 문구를 시스템 프롬프트에 포함
  4. 수집→요약→게시 루프를 정기 실행으로 반복

## 강의·AX 활용 포인트

- 소규모 개인 프로젝트지만 "특정 주제를 실시간으로 감시·정리하는 에이전트"라는 패턴은
  뉴스 모니터링·경쟁사 동향 추적 같은 업무에도 그대로 옮길 수 있다 — 이 위키의
  [[ai-radar-daily-scan-pipeline]]과 같은 패턴군으로 강의에서 함께 소개하기 좋다.
- 진입장벽이 낮은(난이도: 하) 실습용 데모로 활용 가능.
