# Suki의 비개발자 클로드코드 업무 자동화 — "빈 폴더 + 설정 파일 3개"

> **공식**: [Claude Code + Claude 크롬 확장]으로 [CLAUDE.md·skill.md·agent.md 3파일 프로젝트 구성]을 활용해 [SNS 콘텐츠 생성·PPT 변환·노션 문서화·링크드인 데이터 수집]을 수행 → [밤샘급 문서 작업 자동 완료, 사례가 강의 상품화]

## 무엇을 자동화했나

비개발자 저자 Suki가 브런치 2부작(2026-02-06 / 02-13)으로 공개한 실전 기록.

| 업무 | 도구 | 내용 |
|------|------|------|
| 파일 작업 | Claude Code | PDF 여러 개 병합, 엑셀 특정 열 추출 등 즉시 실행 |
| SNS 콘텐츠 시스템 | Claude Code | 사이트 주소+주제 입력 → 브랜드 에셋 저장 → 인스타 카드뉴스·릴스 시나리오·링크드인 글·스레드 글 자동 생성 |
| PPT→마크다운 | Claude Code + 스킬 | 328쪽 PPT 변환 — 첨부 용량(31MB)·컨텍스트 한계를 작업 분할·반복으로 돌파 |
| 노션 문서화 | Claude Code + 노션 API | 팁·프롬프트 모음집, 90일 캘린더를 노션에 자동 생성 |
| 링크드인 데이터 수집 | Claude 크롬 확장 | TOP 50 글을 제목·링크·좋아요·댓글·퍼감·노출수 표로 추출 → 엑셀 붙여넣기 |
| 링크 페이지 구축 | Google Antigravity (병용) | 종료된 Linktree bento 페이지를 HTML 기반 재구현 (Gemini 3 Flash 무료) |

## 어떻게 구성했나 (아키텍처)

- **3파일 최소 구조**: 작업 폴더에 `CLAUDE.md`(프로젝트 규칙) + `skill.md`(작업 능력) + `agent.md`(역할 지정). 스킬은 skillsmp.com / skills.sh 에서 다운로드하거나 Claude에 직접 생성 요청.
- **셋업도 위임**: 빈 폴더에서 "잘 쓰는 사람들의 노하우를 모은 프로젝트 셋팅 가이드" 파일을 참고시켜 "이 업무에 적합한 프로젝트 셋팅해줘"라고 요청 — 에이전트·스킬 구성 자체를 Claude Code가 만든다.
- **도구 사용 기준**: 복잡·긴 맥락 업무는 Claude Code(토큰 소모 큼, Pro 필요), 간단·빠른 구현은 Antigravity(무료, 느림), 웹 페이지 위 작업은 크롬 확장.

## 벤치마크 데이터

| 항목 | 값 | 근거 |
|------|-----|------|
| 모델 | 미확인 (Antigravity 병용 건은 Gemini 3 Flash) | 원문 |
| 비용 | Claude Pro $20/월. 건당·토큰 비용 미확인 | 원문 (2편 도구 비교표) |
| 권한 | 대화형 승인 — "승인을 위해 계속 1을 누르다보니" (자동 승인 미사용) | 원문 (1편) |
| 성숙도 | production — 본인 실무(강의 제작·뉴스레터·SNS 운영)에 상시 사용 | 원문 |

## 성과와 수치

- **일화(anecdotal)**: "수동으로 진행했다면 밤을 새워야 했을" 수준의 효율화(328쪽 PPT→노션 백서·캘린더). 정량 수치는 원문에 없음.
- 간접 지표: 이 사례를 기반으로 인프런 강의 출시 — 수강생 171명, 평점 4.5 (1편 시점).

## 재현 가이드

- **난이도**: 하~중 (터미널 설치 1회가 유일한 장벽)
- **준비물**: Claude Pro 구독, Node.js v18+, 터미널(맥)/Git Bash(윈도우), `npm install -g @anthropic-ai/claude-code`
- **핵심 단계**:
  1. 자동화할 업무 1개를 고르고 빈 폴더 생성, `cd`로 이동 후 `claude` 실행
  2. 잘 정리된 셋팅 가이드 문서를 폴더에 넣고 "이 파일 참고해서 ○○ 프로젝트 만들어줘" 요청 — CLAUDE.md·스킬·에이전트를 Claude Code가 생성
  3. 생성된 프로젝트에 실제 업무를 프롬프트로 지시, 승인하며 진행
  4. 잘 된 작업은 스킬(.md)로 저장해 재사용

## 강의·AX 활용 포인트

- **강의**: "빈 폴더 + 설정 파일 3개"라는 최소 구조가 비개발자 입문 커리큘럼의 좋은 출발점. "셋업 자체를 AI에게 시킨다"는 메시지가 심리적 장벽을 낮춘다. 이미 강의 상품(인프런)으로 검증된 구성이라 시장성 참고 자료도 된다.
- **AX**: 개발자 아닌 직원의 Claude Code 도입 가능성을 보여주는 국내 1차 사례 — 단 성과가 일화 수준이므로 교육 효과 근거로는 보조 자료로 활용.
