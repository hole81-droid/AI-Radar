# Claude "/design" 스킬 4단계 — 디자인 시스템→템플릿→스킬→휴먼인더루프

> **공식**: Claude(신규 Skill 기능 "/design")로 skills를 활용해 디자인 시스템·재사용
> 템플릿 제작을 수행 → 반복되는 디자인 작업을 4단계 워크플로로 표준화(정량 성과 미확인)

## 무엇을 자동화했나

AI 자동화 유튜버 Ben AI(BenAI92)가 2026-09-08 "Claude's New Skill Just Changed
Design Forever (/design)" 영상에서 Claude의 새 디자인 관련 Skill을 활용해 반복
디자인 작업을 표준화하는 4단계 프로세스를 시연했다. 매번 처음부터 디자인 지시를
새로 하는 대신, 디자인 시스템과 템플릿을 스킬로 한 번 만들어두고 이후 작업에서
재사용하는 접근이다.

## 어떻게 구성했나 (아키텍처)

영상 챕터 구성 기준 4단계:

1. **디자인 시스템 만들기**: 색상·타이포그래피·레이아웃 규칙을 Claude 안에서 재사용
   가능한 디자인 시스템으로 정리한다.
2. **템플릿 만들기**: 디자인 시스템을 바탕으로 슬라이드·소셜 카드 등에 쓸 재사용
   템플릿을 제작한다.
3. **디자인 스킬 만들기**: 위 시스템·템플릿을 Claude의 Skill로 패키징해, 이후에는
   매번 처음부터 설명하지 않고 스킬을 호출하는 것만으로 같은 품질의 결과를 반복
   생성할 수 있게 한다.
4. **휴먼인더루프(Human in the Loop)**: 자동 생성 결과를 사람이 검수·피드백하는
   단계를 워크플로에 명시적으로 넣어, 스킬이 자동화하되 품질 통제는 사람이 유지하도록
   구성한다.

영상 설명란에는 이 4단계 챕터 제목 외의 구체적 수치·툴 세부사항은 공개돼 있지 않다
(제작자 본인 강의·에이전시 홍보 링크 위주).

## 성과와 수치

원문에 구체적 정량 성과(제작 시간 단축·비용 절감 등)는 없다. "디자인이 영원히
바뀌었다"는 제목은 마케팅적 과장이며, 실제 확인 가능한 것은 4단계 워크플로 구조
자체다.

## 재현 가이드

- **난이도**: 중
- **준비물**: Claude 계정(Skill 기능 접근 가능한 플랜), 기존에 쓰던 브랜드 색상·
  폰트·레이아웃 규칙(있다면 재사용, 없다면 새로 정의)
- **핵심 단계**:
  1. 자사/개인 브랜드의 색상·타이포그래피·레이아웃 규칙을 정리한다.
  2. 이를 Claude 안에서 디자인 시스템으로 변환한다.
  3. 자주 만드는 산출물(슬라이드 등) 유형별로 재사용 템플릿을 제작한다.
  4. 시스템+템플릿을 Skill로 패키징해 저장한다.
  5. 이후 생성물마다 사람이 검수하는 단계를 워크플로에 고정한다.

  두 사례를 나란히 놓고 비교 강의 소재로 쓸 수 있다.
- **AX**: 사내 디자인 표준(브랜드 가이드)을 스킬로 코드화해 배포하면, 비전문 부서
  구성원도 브랜드에 맞는 산출물을 자동으로 만들 수 있다는 방향성 — 다만 이 사례
  자체는 성과 수치가 없어 도입 전 자체 파일럿으로 검증이 필요하다.
