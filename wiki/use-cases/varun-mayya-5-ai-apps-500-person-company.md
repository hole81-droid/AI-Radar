# "500명 회사를 AI로 만든 앱 5개로 돌린다" — Varun Mayya의 Aeos 사내 도구 공개

> **공식**: AI(Wan 2.1 파인튜닝 등)로 사내 맞춤 앱 5종 직접 구축(vibe-coding)을 활용해 500명 미디어 기업의 영상 제작 전 과정을 수행 → 더빙 3배 속도·월 1,000+ 아바타 영상·누적 2,000+ 영상 제작

## 무엇을 자동화했나

인도의 기업가·크리에이터 Varun Mayya가 2026년 7월 초 영상 "5 Apps I Built With AI to Run
My 500-Person Company"에서 공개. 그가 운영하는 미디어테크 기업 Aeos(직원 500+, 무투자
부트스트랩, Red Bull·Amazon Prime·IPL 팀 등이 고객)의 영상 제작 파이프라인을 개발자를
고용해서가 아니라 창업자가 AI로 직접 만든 사내 앱들로 자동화했다.

1. **AI Avatar Engine** — Heygen 비의존 자체 파인튜닝 아바타(Wan 2.1 커스텀 파인튜닝), 월 1,000개+ 영상 생산
2. **AlphaCTR** — CTR 최적화 썸네일·광고 크리에이티브 생성기 (얼굴 재구성 정확도 99% 주장)
3. **AI Face Inpainting (Presenter Swap)** — 기존 영상에 AI 진행자를 합성
4. **Infographic Generator** — 스크립트를 넣으면 데이터 포인트를 자동 감지해 애니메이션 차트 영상 생성
5. **AI Multilingual Dubbing** — 힌디·칸나다·타밀어 번역+립싱크 더빙, 기존 더빙의 3배 속도 (RCB용으로 개발 후 전사 배포)

## 어떻게 구성했나 (아키텍처)

- 만든 주체는 개발팀이 아니라 창업자 본인 — 시민 개발([[citizen-development]])의 상한선을
  끌어올린 사례. 단, 사내 Labs 조직(25명+, 소프트웨어 엔지니어 밀도 높음)이 도구를 운영·확장한다.
- 아바타 엔진은 오픈 모델 **Wan 2.1을 자체 파인튜닝** — 외부 SaaS(Heygen) 의존을 제거하고
  자사 워크플로우 맞춤형으로 내재화한 build-not-buy 구조.
- 각 도구는 특정 병목(더빙 속도, 썸네일 CTR, 진행자 촬영 비용)을 겨냥한 단일 목적 앱이며,
  완전 자동화가 아니라 **유닛 이코노믹스 개선** 목적으로 배치 — 주력 채널 YAAS의 일일 수백 편
  영상 중 절반 이상은 여전히 실촬영이다.
- 사용된 코딩 도구(Claude Code·Cursor 등)는 원문에서 미확인.

## 성과와 수치

- 더빙 3배 속도, 아바타 영상 월 1,000개+, 누적 2,000개+ 영상 제작 — **자사 주장(claimed)**
- AlphaCTR 얼굴 재구성 99% 정확도 — **자사 주장(claimed)**, 측정 방법 비공개
- 부수 산출물: 사내용으로 만든 온프레미스 영상 스토리지 VideoVault를 "클라우드 대비 10배
  빠름"(주장)으로 외부 SaaS화 — 사내 도구가 신사업이 되는 경로

## 재현 가이드

- **난이도**: 상 (오픈 모델 파인튜닝 + 영상 파이프라인 구축)
- **준비물**: 반복 병목이 명확한 콘텐츠 워크플로우, GPU 인프라(파인튜닝용), 도구를 운영할 최소 인력
- **핵심 단계**:
  1. 영상 제작 파이프라인에서 단가·속도 병목 5개를 지목한다 (더빙, 썸네일처럼 구체적으로)
  2. 병목당 단일 목적 앱 1개를 AI로 구축 — 범용 플랫폼을 만들지 않는다
  3. 외부 SaaS 의존 구간(아바타 등)은 오픈 모델 파인튜닝으로 내재화를 검토한다
  4. "완전 자동화"가 아니라 처리량·단가 지표(3배 속도 등)로 효과를 측정한다
  5. 검증된 사내 도구는 외부 상품화(VideoVault 경로)를 검토한다

## 강의·AX 활용 포인트

- **AX**: "반복 업무 중 사내 도구로 만들면 되는 것" 발굴 워크숍의 벤치마크. SaaS 구독 절감이
  아니라 **처리량 3배** 같은 속도 관점 ROI 프레임, 그리고 build-not-buy가 500명 규모 조직에서도
  작동한다는 근거. 맞춤 도구가 곧 경쟁우위("우리 회사만의 소프트웨어")가 되는 논리.
- **강의**: 수강생 각자의 업무로 '나만의 앱 5개' 기획을 시키는 과제 포맷으로 차용 가능.
