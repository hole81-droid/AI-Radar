# Simon Willison — Claude 에이전트로 오픈소스 릴리스 QA, 실측 비용 $149.25

> **공식**: Claude Code for web(claude-fable-5) 메인 세션 + 영역별 서브에이전트 + GPT-5.5 교차검증을 활용해 오픈소스 라이브러리 릴리스 전 QA를 수행 → 릴리스 차단 버그 5건+추가 P1 버그 2건 발견·수정, 실측 비용 $149.25

## 무엇을 자동화했나

유명 개발자 도구 저자 Simon Willison이 자신의 오픈소스 라이브러리 `sqlite-utils` 4.0rc2
릴리스 준비를 Claude 에이전트에게 맡긴 과정과 비용을 상세히 공개한 사례. 릴리스 전 최종
QA 전체 — 릴리스 차단 버그 식별·분류, 코드 수정, 문서 작성, 릴리스 노트 작성을 자동화했다.

## 어떻게 구성했나 (아키텍처)

- **메인 세션**: Claude Code for web(Claude Max 구독, claude-fable-5)에 "안정 릴리스 전 마지막
  주의사항 식별"이라는 프롬프트로 시작해 5개의 릴리스 차단 이슈를 식별.
- **영역별 서브에이전트**: API 검토, 트랜잭션/원자성 검토, 커밋 검토, 마이그레이션 검토를
  각각 전담하는 서브에이전트를 병렬로 투입해 교차 검증.
- **이종 모델 교차검증**: 이후 GPT-5.5로 별도 재검토를 수행해 추가 P1 버그 2건을 더 발견 —
  단일 모델 사각지대를 이종 모델로 보완.
- 총 37개 프롬프트·34개 커밋으로 30개 파일을 수정했고, Claude Code for web에서 10~15분
  단위로 결과를 검토하며 진행.

## 벤치마크 데이터

| 항목 | 값 |
|---|---|
| 모델 | claude-fable-5(메인+서브에이전트) + GPT-5.5(교차검증) |
| 비용 | 총 $149.25 (메인 세션 $141.02, 나머지는 서브에이전트·교차검증) — **실측** |
| 권한 | 미확인 |
| 성숙도 | production (실제 릴리스에 적용) |

## 성과와 수치

- **실측**: 총비용 $149.25, 프롬프트 37개, 커밋 34개, 수정 파일 30개.
- 가장 심각한 버그: `delete_where()`가 커밋되지 않아 연결이 오염되고 후속 작업이 모두
  롤백될 수 있는 문제 — 실제 프로덕션 사고를 사전에 막은 사례.
- 저자 스스로 "서브에이전트에는 더 저렴한 모델을 썼어야 했다"고 반성 — 비용 최적화 여지가
  있음을 실측 기반으로 인정.

## 재현 가이드

- **난이도**: 중
- **준비물**: Claude Code for web(Claude Max), 검토 영역별 서브에이전트 구성, 교차검증용
  이종 모델(GPT 계열 등)
- **핵심 단계**:
  1. "릴리스 전 마지막 주의사항 식별" 같은 명확한 QA 목표로 메인 세션 시작
  2. 검토 영역(API/트랜잭션/커밋/마이그레이션)별로 전담 서브에이전트를 병렬 투입
  3. 동일 모델의 사각지대를 줄이기 위해 이종 모델로 2차 교차검증
  4. 10~15분 단위로 결과를 사람이 직접 검토하며 진행
  5. 비용을 세션·에이전트 단위로 나눠 기록해 사후 비용 최적화 지점을 파악

## 강의·AX 활용 포인트

- **강의**: 서로 다른 모델(Claude·GPT)로 교차 검증하는 패턴은 "에이전트 QA의 신뢰도를 어떻게
  높이는가"를 가르치는 좋은 실습 소재.
- **AX**: 내부 소프트웨어 릴리스 QA에 에이전트를 투입할 때의 **실측 비용 벤치마크**로 바로
  활용 가능 — [[ai-radar-daily-scan-pipeline]]과 함께 이 위키에서 모델·비용이 모두 확인된
  드문 케이스.
- 저자의 "서브에이전트는 더 저렴한 모델로" 반성은 비용 최적화 강의에서 구체적 반례로 쓰기 좋다.
