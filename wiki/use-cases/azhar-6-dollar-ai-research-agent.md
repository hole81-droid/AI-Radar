# Azeem Azhar — 개인 리서치 에이전트 "RMA" 운영비 실측, 피크 $494/일 → $6/일

> **공식**: Claude Code·OpenAI Codex·Elicit·Manus API를 조합한 개인 리서치 에이전트
> "R Mini Arnold"(RMA)로 코드 통합·논문 리서치·글쓰기 보조를 수행 → 일일 운영비가
> 피크 $494에서 $6로 하락(저자 본인 실측 지출 기준)

## 무엇을 자동화했나

Exponential View 발행인 Azeem Azhar가 본인이 실제로 매일 쓰는 개인 AI 에이전트
"R Mini Arnold"(RMA)의 운영비 변화를 공개했다. RMA는 코드 작업, 학술 논문 리서치, 내부
리서치 도구 접근, 특정 작업 위임을 하나의 개인용 에이전트 파이프라인으로 묶은 구성이다.

## 어떻게 구성했나 (아키텍처)

- **코드 통합**: Claude Code·OpenAI Codex를 통한 코드 작성·통합
- **학술 리서치**: Elicit을 통한 논문 검색·리서치
- **내부 도구**: 자체 리서치 그래프 도구("Prism graph") 연동
- **작업 위임**: Manus API 연동으로 특정 유형 작업을 별도 위임
- 여러 상용 AI 도구·API를 하나의 개인 워크플로우로 엮은 **CLI/도구 파이프라인** 형태 —
  단일 통합 플랫폼이 아니라 도구 조합이라는 점이 특징.

## 벤치마크 데이터

| 항목 | 값 |
|---|---|
| 모델/도구 | Claude Code, OpenAI Codex, Elicit, Manus(구체 모델명은 미확인) |
| 비용 | 현재 일 $6(연 약 $2,000) — 이전 기준선 일 $50~60 — 피크 일 $494. **저자 본인 실측 지출** |
| 권한 설계 | 미확인 |
| 성숙도 | production (저자가 실제 매일 상시 사용 중) |

## 성과와 수치

- **실측(저자 본인 지출 기준)**: 일일 운영비가 피크 $494에서 현재 $6로 하락 — 약 82배
  절감. 이전 "정상" 기준선이었던 일 $50~60에서도 약 8~10배 절감.
- 저자는 비용 하락 원인으로 Anthropic·OpenAI 간 가격 경쟁(중국 모델들의 성능 향상이
  촉발)을 지목.
- 비교 참고 수치(저자 본인 사례 아님, 인용된 타사 사례): **Amazon**이 유사한 Claude 기반
  프로젝트에 5개월간 **$1.8M**을 지출했다는 사례가 함께 언급됨 — "AI 관련 지출이 얼마나
  드는지 파악하기 어렵다"는 Amazon 내부 직원 발언과 함께 인용.
- 시장 맥락 수치(서베이 기반, 저자 실측 아님): 미국 상위 1% 기업은 직원 1인당 연
  $7,400을 AI에 지출한다는 데이터도 함께 제시.

## 재현 가이드

- **난이도**: 중
- **준비물**: 코딩 에이전트(Claude Code·Codex 등) 구독, 논문 리서치 도구(Elicit 등),
  작업별 위임처(Manus 등 태스크 특화 에이전트/API)
- **핵심 단계**:
  1. 반복되는 개인 업무를 유형별로 분류(코드/리서치/문서 등)
  2. 유형별로 가장 저렴하고 적합한 도구를 배정(단일 벤더에 올인하지 않음)
  3. 일별 지출을 실제로 추적 — "얼마나 드는지 모른다"는 함정을 피하기 위해 비용을
     세션·도구 단위로 기록
  4. 가격 경쟁이 심한 구간에서는 정기적으로 도구·플랜을 재점검해 비용을 재협상

## 강의·AX 활용 포인트

- **강의**: 개인 생산성 차원의 "에이전트 라우팅"([[ai-agent-routing]] 참고) 실사례 —
  기업 사례가 아니라 개인이 여러 상용 도구를 조합해 쓴 리서치임에도 비용을 실측
  공개했다는 점에서 투명성 있는 벤치마크 소재.
- **AX**: "AI 비용이 얼마나 드는지 파악하기 어렵다"는 Amazon 사례와 대비해, 개인·팀
  단위로 AI 지출을 세션·도구별로 추적하는 습관의 중요성을 보여주는 반례로 쓸 수 있다.
  가격 경쟁이 실제 최종 사용자 비용을 8~80배 수준까지 낮출 수 있다는 실측 근거이기도
  하다.
