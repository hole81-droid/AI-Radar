# Google DeepMind LearnLM × Fab AI — 시에라리온 수학 수업 Gemini Guided Learning RCT

> **공식**: Gemini로 "Guided Learning"(스캐폴딩형 AI 학습 기능)을 활용해 시에라리온 중학교
> 수학 수업의 절반을 재설계 → 8주 만에 학습 성과 +0.258 SD(추가 학습 진도 약 1.2~1.7년 상당)
> 확보, 교사 훈련은 단 하루(5~6시간)

> **채택 경위**: EdSurge 2026-06-12 오피니언("AI Won't Replace Educators...")이 인용한
> 각주 링크를 따라간 **1차 원문**(Google DeepMind·Fab AI 공동 기술보고서, 2026-05-15
> 발행, `goo.gle/LearnLM-SierraLeone-May26`). EdSurge는 사후 결과만 한 문단으로 요약했고,
> 이 페이지는 PDF 원문의 설계·수치를 직접 정독해 채웠다. AI 교육 트렌드 매체 백필
> (2026-05-01~07-14 구간, 2026-09-10 수행) 최대 발견.

## 무엇을 자동화했나

**"AI가 학생에게 정답을 준다"가 아니라 "교사가 이끄는 구조화된 협업 활동에 AI를 결합한다"는
설계다.** Google DeepMind LearnLM 팀과 현지 교육 스타트업 Fab AI가 시에라리온 Port Loko
지구의 정부 지원 공립 중학교 12곳, 7~8학년 수학 교실 48개를 대상으로 사전등록 RCT를 수행했다.
같은 학교·같은 학년 안에서 교실을 무작위로 절반씩 나눠(클러스터 무작위배정), 절반은 주간
수학 수업(주 4교시) 중 2교시(90분)에 Gemini 앱의 Guided Learning 기능을 쓰게 하고, 나머지
절반은 표준 수업을 그대로 유지했다. 총 8주(실제 운영은 지구별 시작일 차이로 9주에 걸쳐 진행),
목표 사용 시간은 **12시간**.

## 어떻게 구성했나 (아키텍처)

**교사 훈련**: 실험군·대조군 교사 전원에게 **동일하게 5~6시간, 단 하루** 훈련을 진행했다
(훈련 차이가 결과를 왜곡하지 않도록 통제군 교사도 동일 훈련을 받되 실제 수업엔 미적용).
훈련 내용: 기기 사용법, Gemini 앱·Guided Learning 소개, 수업 설계 방법, 학생 참여 촉진법.

**수업 진행 4단계** (교사가 매 Guided Learning 수업마다 반복):
1. 학습 목표 제시
2. 학생을 2인 1조로 묶어 Gemini와 함께 수업 내용을 다루게 함
3. 학급 토론으로 학습을 통합
4. 핵심 내용 정리

교사는 **학습 목표 정의와 시작 프롬프트·질문 설계**를 직접 맡았다(수업 준비 단계). 기기는
학생 2인당 1대(태블릿 또는 데스크톱) 공유. 실험은 총 9주 중 모델 업데이트(11월 18일)가
있어 전반 6주는 Gemini 2.5 Pro, 후반 3주는 Gemini 3.0 Pro로 자연스럽게 전환됐다 — 즉 이
결과는 **특정 모델 버전의 성능이 아니라 "교사 설계 + 학생 협업 + Guided Learning 기능"이라는
개입 자체의 효과**로 해석해야 한다(원문이 명시).

**측정 설계**: 결과 측정의 편향을 막기 위해 Oxford MeasurEd에 커리큘럼 정렬 수학 평가(사전·
사후) 제작·시행을 외주. 문항반응이론(IRT)으로 문항 난이도와 학생 실력을 분리해 사전·사후를
공통 척도로 비교. 학생-Gemini 대화 전체를 비식별화 파이프라인 처리 후 수집해 상호작용의
교육적 질도 별도 분석. 트라이얼 종료 후 참여 교사 포커스그룹 + 귀납적 주제 분석.

## 벤치마크 데이터

| 항목 | 값 |
|---|---|
| 모델 | Gemini 2.5 Pro(전반 6주) → Gemini 3.0 Pro(후반 3주) — Guided Learning 기능 |
| 비용 | 미확인 (기기는 2인 1조 공유, 금액 미공개) |
| 권한 설계 | 교사가 활성화·설계 전담, 학생 대화 자동 비식별화, 통제군은 앱 미사용으로 격리 |
| 성숙도 | pilot — 사전등록 RCT, "여러 국가에 걸친 트라이얼 시리즈"의 첫 보고서(확장 전) |
| 근거 수준 | **measured** — N=1,763명, 48개 교실, 12개교, 클러스터 무작위배정 RCT |

## 성과와 수치

**전체 효과**: 의도치료효과(ITT) **+0.258 SD**(95% CI [0.027, 0.488], p=0.029) —
사전 평가에서 코호트 중앙(50백분위)이던 학생이 사후 평가에서 60백분위로 올라간 것과
동등. 저·중소득국 학습 진도 통계와 비교하면 **약 1.2~1.7년치 추가 학습 진도**에 해당.
인구통계 공변량 보정 후에도 +0.259 SD(p=0.031)로 안정적.

**사용량(uptake)**: 요청한 12시간 사용을 채운 학생이 **69.0%**(연구팀 예상을 크게 상회 —
"교육 개입에서 자발적 채택률은 보통 5% 안팎에 머문다"는 게 기존 통념). 실험군 교실의
실제 평균 사용 시간은 **약 15시간**(요청치 대비 25% 초과). 12시간을 채운 학생만 보면
치료효과(TOT) **+0.380 SD**(95% CI [0.040, 0.719], p=0.029). 사용 시간 1시간 추가마다
+0.016 SD(p=0.026)의 선형 효과.

**이질성**: 사전 수학 실력이 1 SD 높은 학생일수록 효과가 +0.195 SD 더 컸다(p=0.002) —
즉 **이 개입은 원래 잘하던 학생에게 더 유리했다**(교육기술의 흔한 격차 확대 패턴).
연구팀은 원문에서 이를 명시적 한계로 인정하고, 향후 트라이얼은 **뒤처진 학생에게 더 큰
효과를 내도록** 페다고지·활동 설계·관계적 요소를 조정할 계획이라고 밝혔다.

**상호작용 품질**: 학생-Gemini 대화 113,344개 메시지, 7,421개 세션. **97.4%가 과제 집중**
(주제 이탈 낮음). 학생이 직접 정답을 구하는 메시지는 5.0%뿐, 91.4%는 이해·역량 구축
방향. Gemini 응답의 76.4%는 정답 제공이 아니라 **스캐폴딩 질문**, 직접 정답 제공은 2.1%뿐.

**교사 반응**: 포커스그룹에서 두 주제가 반복 등장 — 학생의 열의(수업에 더 빨리 오고 Gemini
시간을 더 달라고 요청), 그리고 **Gemini가 교사 자신의 교수 전문성 확장에도 도움**이 됐다는
증언(익숙한 주제를 가르치는 새 방법을 발견).

## 재현 가이드

**난이도: 상** — RCT 설계·비식별화 파이프라인·IRT 채점은 연구 인프라가 필요하다. 단
**"수업 설계·훈련 방식"만 떼어내면 난이도는 중**이다.

**준비물**: 학생 2인당 기기 1대, AI Guided Learning 기능(또는 유사 스캐폴딩형 AI),
교사 대상 5~6시간 단회 훈련, 4단계 수업 설계 템플릿, 사전·사후 평가(또는 대체 KPI).

**핵심 단계**
1. **AI 사용을 "정답 제공"이 아니라 "협업 스캐폴딩"으로 설계한다** — 응답의 76%를
   질문형으로 만들면 학생이 과업에서 이탈하지 않는다(97.4% 과제 집중률의 근거).
2. **교사 훈련은 단 하루, 5~6시간으로 충분하다** — 도구 숙련이 아니라 "이 도구로 어떤
   활동을 설계할지"에 집중했기 때문.
3. **목표 사용량을 명시적으로 요청하고 실제 이수율을 추적한다** — "요청 12시간 → 실제
   69%가 채움 → 평균 15시간"처럼, 명시적 목표치 제시가 자발적 채택률(통상 5%)을
   크게 웃돌게 만든 핵심 변수로 읽힌다.
4. **학생 대화 로그를 정성 분석해 도구 품질을 검증한다** — "질문 대 정답" 비율을
   실측하지 않으면 AI가 실제로 사고를 유도하는지 확인할 방법이 없다.
5. **격차 확대 리스크를 사전에 명시하고 다음 라운드에서 보정한다** — 이 트라이얼처럼
   상위권이 더 이득을 본 사실을 숨기지 않고 다음 설계에 반영하는 것 자체가 재현 가치다.

## 강의·AX 활용 포인트

- **강의**: "AI Mini Camp" 같은 원데이형 실습 과정의 설계 근거로 직접 쓸 수 있다 —
  이 연구가 입증한 것은 "장시간 도구 연수"가 아니라 **"단 하루 훈련 + 명확한 활동
  구조(4단계) + 명시적 목표 이수량"**이 실제 성과로 이어진다는 점이다. 교사가 프롬프트를
  직접 설계하게 한 것도 "도구 사용법 암기"보다 "활동 설계 역량"에 방점을 찍은 사례로
  인용 가능.
- **AX**: "AI가 직접 답을 주는 도구"보다 "질문으로 되돌려주는 도구"가 몰입도와 성과
  모두에서 우세하다는 실측 근거 — 사내 AI 어시스턴트·챗봇 설계 시 "정답 자동 완성"보다
  "스캐폴딩형 응답"을 지향할 근거로 인용 가능. 자발적 채택률 통념(5%)을 명시적 목표
  제시로 69%까지 끌어올린 사례는 **사내 AI 툴 도입 캠페인의 목표 설계(정량 이수 기준
  제시)**에 그대로 적용된다.
- **한계**: 저자들이 직접 명시한 대로 상위권 학생에게 유리하게 작용했다(격차 확대
  리스크). 또한 이 보고서는 "여러 국가 트라이얼 시리즈의 첫 편"이라 장기 지속효과는
  아직 미확인이다. 비용 수치도 원문에 없다.
