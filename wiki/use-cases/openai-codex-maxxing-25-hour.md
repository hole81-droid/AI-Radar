# "Codex-maxxing" — Codex 25시간 연속 자율 작업으로 3만 줄 코드 완성

> **공식**: OpenAI Codex(GPT-5.1-Codex-Max)로 지속 스레드(durable thread)+검증가능한 목표 분할을 활용해 대형 개발 작업의 장시간 무인 수행을 시연 → 25시간 연속 실행, 약 1,300만 토큰, 약 3만 줄 코드 생성 (공식 발표)

## 무엇을 자동화했나

OpenAI가 "Codex-maxxing"이라는 이름으로 공개한 백서 겸 시연 사례. 하나의 큰 개발 목표를
사람 개입 없이 며칠에 걸쳐 진행할 수 있도록 설계한 장시간 작업 노하우를 담았으며, 실제
시연에서 Codex가 25시간 연속 실행되며 약 1,300만 토큰을 사용해 약 3만 줄의 코드를 생성했다.

## 어떻게 구성했나 (아키텍처)

- **지속 스레드(durable thread)**: 대화를 매번 새로 시작하지 않고 컨텍스트를 이어가는 방식으로,
  긴 작업 동안 누적된 결정·상태를 유지.
- **검증 가능한 목표 분할**: 큰 목표를 작은 단위로 쪼개 각 단위의 완료 여부를 명확히 검증할
  수 있게 설계 — 시간이 아니라 "완료 조건 충족"으로 다음 단계 진행을 판단.
- **프로젝트 메모 체계**: 결정사항·담당(역할)·진행 상태 등을 사람이 열어보고 직접 고칠 수 있는
  파일로 남겨, 장시간 실행 중에도 사람이 개입·감독할 수 있는 지점을 확보.

## 벤치마크 데이터

| 항목 | 값 |
|---|---|
| 모델 | GPT-5.1-Codex-Max (여러 컨텍스트 윈도우를 이어 붙이는 압축 기법으로 장시간 작업에 특화) |
| 비용 | 미확인 — 토큰 사용량(약 1,300만)만 공개, 달러 환산 비공개 |
| 권한 | 미확인 |
| 성숙도 | demo (공식 백서·시연 사례, 일반 사용자 재현 가이드는 별도) |

## 성과와 수치

- **공식 발표 수치**: 25시간 연속 실행, 약 1,300만 토큰 사용, 약 3만 줄 코드 생성.
- 외부 독립 검증은 없어 **주장(claimed)** 수준으로 분류하나, 수치 자체는 OpenAI가 자사 제품
  시연으로 구체적으로 제시한 값이다.

## 재현 가이드

- **난이도**: 중 (Codex 자체 기능 활용, 별도 인프라 구축 불필요)
- **준비물**: OpenAI Codex(GPT-5.1-Codex-Max 이상), 장시간 작업에 적합한 개발 목표
- **핵심 단계**:
  1. 큰 목표를 검증 가능한 작은 단위(마일스톤)로 분할
  2. 각 단위의 "완료/막힘" 조건을 명확히 정의 (시간 기반 종료 금지)
  3. 프로젝트 메모 파일에 결정사항·상태를 기록해 사람이 언제든 열람·수정 가능하게 유지
  4. 대화를 새로 시작하지 않고 지속 스레드로 이어가며 장시간 실행

## 강의·AX 활용 포인트

- "며칠짜리 프로젝트를 AI에게 통째로 맡길 때 맥락을 어떻게 유지하는가"에 대한 공식 설계
  패턴 — 장기 프로젝트형 AX 파일럿 설계 시 참고 자료로 적합.
- 개발자 대상 자료지만 "AI가 하루 넘게 혼자 일한다"는 결과 자체는 비개발자 대상 강의에서도
  화제성 있는 사례로 쓸 수 있다.
- 유사 패턴인 [[agent-loops-daily-pr-review]](목표 기반 루프)와 함께 "시간이 아니라 완료 조건
  기준으로 자동화를 설계한다"는 공통 원칙을 강의할 수 있다.
