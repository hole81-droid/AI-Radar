# Codex로 이메일·메신저·캘린더를 한 번에 처리하는 개인 비서 에이전트

> **공식**: OpenAI Codex + Google Workspace CLI(gogcli) + WhatsApp CLI(wacli) + 브라우저/macOS 자동화를 활용해 이메일·멀티메신저 확인·캘린더 관리를 수행 → 20분 걸리던 확인 작업을 약 10초로 단축 (주장)

## 무엇을 자동화했나

한 사람이 Codex를 중심으로 여러 메신저와 구글 워크스페이스를 엮어 만든 개인 업무 자동화
스택의 실전 후기. 이메일 작성·발송, 왓츠앱·텔레그램·아이메시지를 가로지르는 "무엇을
놓쳤나" 확인, 소개 이메일 초안 작성, 구글 드라이브 문서 갱신, 캘린더 일정 생성을 자동화했다.

## 어떻게 구성했나 (아키텍처)

- **도구 계층화**: API/CLI 우선 → 로컬 파일 → 브라우저 자동화 → 화면(OS) 자동화 순으로
  우선순위를 두고, 가능한 한 안정적인 상위 계층부터 시도.
- **중앙 데이터 소스**: 구글 드라이브를 문서·정보의 단일 소스로 삼아 여러 도구가 참조.
- **권한 단계**: 중요한 메시지는 에이전트가 **초안까지만** 만들고 발송은 사람이 승인하는
  단계를 둬서 오작동을 방지.

## 벤치마크 데이터

| 항목 | 값 |
|---|---|
| 모델 | OpenAI Codex |
| 비용 | 미확인 |
| 권한 | 중요 메시지 발송은 사람 승인 필요(초안 생성까지만 자동) — 그 외 세부 권한 범위는 미확인 |
| 성숙도 | pilot (개인 사용 실험, 조직 단위 도입 여부 불명) |

## 성과와 수치

- 저자 주장: 기존 20분 걸리던 멀티앱 확인 작업을 약 **10초**로 단축 — **주장(claimed)** 수준,
  측정 방법·표본 크기는 원문에 구체적으로 제시되지 않음.

## 재현 가이드

- **난이도**: 중
- **준비물**: OpenAI Codex, 구글 워크스페이스 CLI(gogcli 등), 메신저 CLI(wacli 등), 브라우저·OS
  자동화 도구
- **핵심 단계**:
  1. 자동화 대상 앱·메신저를 API/CLI 접근 가능 여부로 분류
  2. API/CLI가 없는 앱은 브라우저 자동화, 그마저 안 되면 화면(OS) 자동화로 계층적 폴백 구성
  3. 문서·정보의 단일 소스(예: 구글 드라이브)를 정하고 모든 도구가 이를 참조하게 설계
  4. 발송·확정 등 되돌리기 어려운 동작은 "초안까지만" 자동화하고 사람 승인 게이트를 둠

## 강의·AX 활용 포인트

- 개인 생산성 자동화에서도 "승인 게이트" 설계가 핵심 안전장치임을 보여주는 사례 —
  기업 개인비서 자동화 강의에서 권한 설계 예시로 활용 가능.
- 도구 계층화(API→로컬파일→브라우저→화면) 순서는 "공식 API가 없는 서비스와의 연동"이라는
  AX 프로젝트에서 흔한 병목을 다루는 실전 패턴으로 인용할 수 있다.
