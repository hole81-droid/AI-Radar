# LLM Wiki 배우기 — 추천 영상·자료

Andrej Karpathy(전 Tesla AI 총괄, OpenAI 공동창업)가 제안한 **LLM Wiki** 패턴:
RAG·벡터DB 없이, LLM 에이전트(Claude Code 등)가 마크다운 위키를 직접 생성·유지하는
개인 지식 베이스. Raw(원본) → Wiki(AI가 관리) → Schema(CLAUDE.md) 3레이어 구조.
**이 AI Radar 위키 자체가 이 패턴의 구현체다.**
