# 벤더 공식 고객 사례 수치 모음 (1차 출처, 발표 자료급)

## 핵심 요약

- **Rakuten**: 자율 코딩 세션 7시간, 기능 출시 24일→5일, 정확도 99.9%, Skills 활용 8배 (claude.com/customers 공식).
- **Mozilla Firefox**: 보안 수정 월 20~30건 → 423건 (약 14배) — 위키에 이미 구조화됨: [[mozilla-claude-mythos-firefox-vulnerability-detection]].
- **Anthropic 사내**: 코드의 65%가 Claude Code 작성 [벤더 자체 발표 — 이해관계 주의 병기].
- **비용 감각 앵커**: 에이전트 1건 QA 실측 $149.25 (Simon Willison 개인 실측 — 업계 추정급) — 위키에 이미 구조화됨: [[simon-willison-claude-release-qa]].
- 국내(KT Cloud, 삼일PwC)는 1차 자료이나 수치 없음 — "방향 근거"로만 사용 가능. → [[ktcloud-fe-team-claude-code-adoption]], [[jocoding-ax-series-pwc-samil]]

## 정직성 메모

이 페이지의 수치는 벤더(Anthropic) 또는 고객사가 직접 공개한 발표 자료 기반이다.
독립 검증된 수치가 아니므로 **강의·AX 보고서에 인용할 때는 반드시 출처가 "벤더 자체 발표"임을
함께 명시**한다 — case-catalog의 `evidence: claimed` 기준과 동일한 취급.

## 활용 포인트

- **강의**: "1차 출처만 승격한다"는 팩트 규율을 보여주는 예시 세트 — 벤더 발표 수치와 독립 실측
  수치(Simon Willison, Microsoft 연구 등)를 나란히 놓고 신뢰도 차이를 설명할 때 유용.
- **AX**: 국내 사례가 아직 "수치 없는 방향 근거" 단계라는 점 자체가 시사점 — 국내 도입 조직은
  스스로 실측 데이터를 축적해야 경쟁사 대비 설득력 있는 근거를 가질 수 있다.
