# Codex Remote 정식 출시 — 폰에서 내 컴퓨터의 AI 에이전트를 조종한다

## 무엇이 있었나

OpenAI가 2026-06-25 **Codex Remote를 전 요금제에 정식 출시(GA)**했다. ChatGPT 모바일 앱에서 QR 코드 페어링으로 Codex 앱이 실행 중인 Mac/Windows 호스트에 연결해, 밖에서도 작업을 시작·이어가고 진행 상황을 확인하고 승인(approve)까지 처리할 수 있다.

- 2026-05-14 Mac 대상 모바일 원격 연결로 시작 → 05-29 Windows 지원 → 06-25 전 요금제 GA로 완성된 흐름.
- 원격 워크스페이스를 바로 만들어주는 DigitalOcean Droplet Workspace 플러그인도 함께 추가됐다.
- Codex는 ChatGPT Free 포함 전 요금제에 번들되어 있어, 별도 구독 없이 쓸 수 있다.

## 왜 중요한가 (비개발자 관점)

"AI에게 일 시켜놓고 자리를 뜨는" 사용 패턴이 공식화됐다. 지금까지 에이전트는 컴퓨터 앞에 앉아 지켜봐야 하는 도구였다면, 이제 집 컴퓨터에 작업을 걸어두고 이동 중에 폰으로 결과를 확인·승인하는 식의 **비동기 업무 위임**이 일반 사용자 기능이 됐다. Codex가 코딩을 넘어 Computer Use(데스크톱 자동화)까지 다루는 범용 에이전트로 확장 중이라는 점에서, 이 원격 제어는 개발자만의 이야기가 아니다.

## 활용/시사점

- **학습과정(course)**: "에이전트에게 위임하는 업무 흐름" 실습 소재로 적합 — 작업 지시 → 외출 → 폰에서 진행 확인·승인이라는 시나리오를 무료 플랜으로도 체험시킬 수 있다.
- 장시간 걸리는 작업(리서치, 빌드, 파일 정리)을 걸어두고 승인 지점만 사람이 처리하는 운영 패턴의 표준화를 예고한다.
