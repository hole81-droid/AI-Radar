# Goldman Sachs, 트레이더·뱅커의 Claude Code 접근 제한 — 엔지니어 약 12,000명만 유지

## 무엇이 있었나
Bloomberg 보도(11-02, 2차 요약 [The State of AI](https://www.thestateofai.com/news/goldman-sachs-claude-code-traders-bankers) 경유, HN 905점)에 따르면 Goldman Sachs는 10월 사내 지침을 바꿔 대부분의 트레이더·뱅커가 Claude Code와 Microsoft의 GitHub 도구를 쓰지 못하게 했다. 트레이딩·퀀트 리서치·SW 개발을 겸하는 Strats 등 **엔지니어 약 12,000명(전체 약 47,000명)**은 유지된다. 사유는 생산성·리스크 검토이며, 비용이 한몫했을 가능성은 추정일 뿐 Goldman이 확인하지 않았다. 사내 다중 모델 AI 어시스턴트는 전사에서 계속 쓴다. 대변인은 "최적의 사용처를 판단하기 위해" 도구를 제공한다고만 밝혔다. 4월에는 홍콩 뱅커 플랫폼에서 Claude를 제거한 바 있다(지역·계약 조건 사유). Goldman은 Anthropic IPO의 주관사이기도 하다([[2026-11-10-anthropic-ipo-roadshow]]).

**미확인**: 대체 도구, 제한 대상의 정확한 인원, 비용 절감 여부.

## 왜 중요한가
"전 직원에게 코딩 에이전트 배포"에서 "직무별 선택 배포"로 후퇴한 대형 금융사 사례다. 코딩 에이전트는 개발 직군 밖(트레이더·뱅커)에서 생산성 근거가 약하고 데이터 반출·권한 리스크는 크다는 판단으로 읽힌다. 도입 확대 일변도의 가정에 대한 반례로, 직무별 라이선스 설계의 참고가 된다.
