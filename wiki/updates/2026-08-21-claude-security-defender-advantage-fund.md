# Anthropic, Claude Mythos 5 사이버보안 방어역량을 기업·오픈소스·정부로 확장

## 무엇이 바뀌었나

Anthropic이 Claude Mythos 5의 방어적 사이버보안 역량 접근권을 넓히는 이니셔티브 4종을
동시에 발표했다: (1) **Claude Security 강화** — 엔터프라이즈 고객이 Mythos 5로 코드베이스
취약점 스캔 실행(CWE 분류·신뢰도/심각도 등급·수정안 포함, 모든 패치는 사람 검토 필수),
(2) 서드파티 사이버보안 툴과의 **파트너 통합**, (3) 오픈소스 취약점 패치 작업 조직에 총
**$35M 규모 크레딧**을 지원하는 **Defender Advantage Fund**, (4) 검증된 방어자·정부
파트너로 **Cyber Verification Program 접근권 확대**.

## 왜 중요한가

"가장 위험한 행동은 사용자가 모델에 직접 접근할 때 발생한다"는 논리로, 방어자에게는
스캔 결과·패치안 같은 "특정 산출물"만 주고 모델 직접 조종은 제한하는 방식으로 보안과
접근성의 균형을 잡았다. 사람 검토를 필수 게이트로 둔 설계가 핵심이다.
[[2026-07-02-claude-cyber-jailbreak-framework]](CJS 탈옥 심각도 프레임워크)·
[[2026-07-28-claude-mythos-post-quantum-crypto-break]](HAWK 암호 결함 발견 60시간)에
이어 "공격보다 방어에 AI를 먼저 풀자"는 Anthropic의 메시지가 반복·구체화된 사례다.

## 활용 포인트

- **AX**: 오픈소스 유지보수 조직·보안팀이 실제로 신청 가능한 크레딧 프로그램이라는 점에서
  구체적 도입 경로로 인용 가능.
- 사람 검토 필수화라는 권한 설계는 "AI 보안 도구를 어디까지 자율화할 것인가" 논의의
  참고 사례.
