# xAI 연타 — Voice Agent Builder 베타, 음성 인식 API, 그리고 "Grok Imagine 완성" 선언

## 무엇인가

xAI가 7월 첫 주에 내놓은 발표 묶음.

- **Voice Agent Builder 베타** (7/3): Grok Voice 위에서 전화 응대·상담용 음성 에이전트를
  코드 없이 만드는 플랫폼. 전화 연결(SIP·telephony), 지식 검색, 도구 호출, 가드레일,
  MCP 연동, 통화 리뷰·관측까지 한 화면에 묶었다. 보이스 클로닝도 포함.
- **Speech-to-Text API 정식 출시** (7/3): 25개 언어 음성 인식, 배치·스트리밍 모드.
- **"Done with Grok Imagine"** (7/5): Elon Musk가 이미지·영상 생성 기능 개발 완료를 선언,
  Grok이 채팅·음성·검색·문서분석·영상생성을 갖춘 종합 소비자 AI로 자리 잡았음을 자평.

## 왜 주목할 만한가

- 3사(Anthropic/OpenAI/Google) 밖에서 **음성 에이전트의 노코드화**가 가장 빠르게 진행 중.
  "전화 받는 AI"는 콜센터·예약·아웃바운드 영업 등 매출과 직결되는 영역이라 기업 수요가 크다.
- 텔레포니·가드레일·관측을 번들로 묶은 것은 그동안 스타트업 여러 개(Vapi, Retell 등)를
  조합해야 했던 스택의 수직 통합 — 음성 에이전트 시장의 가격·진입장벽을 동시에 낮춘다.

## 어디에 써먹을 수 있는가

- **AX 관점**: 콜센터 자동화 검토 기업이라면 PoC 비용이 크게 떨어진 시점. 단, 보이스 클로닝
  포함 등 규제·브랜드 리스크 검토(본인 동의, 녹취 고지)가 선행돼야 한다.
- 국내 CS 조직의 "AI 전화 응대" 도입 시나리오를 그릴 때 참조 스택으로 사용.
