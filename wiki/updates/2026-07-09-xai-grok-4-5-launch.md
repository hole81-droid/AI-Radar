# xAI, Grok 4.5 공개 — Elon Musk "Opus급 성능을 더 저렴하게"

## 무엇이 있었나

xAI(SpaceXAI)가 2026-07-08 **Grok 4.5**를 발표하고 2026-07-09 공개 출시했다. 코딩·에이전틱 작업·지식노동을 겨냥한 모델로, Musk는 "Opus급 성능이지만 더 빠르고 저렴하다"고 소개했다.

- **가격**: 입력 $2/출력 $6(백만 토큰당) — Claude Opus 4.7($5/$25)과 OpenAI Sol($5/$30)보다 낮은 가격대.
- **토큰 효율**: "2배 이상의 토큰 효율성"을 강조.
- **개발 배경**: 코딩 에디터 Cursor와 공동 학습(데이터 플라이휠 방식)됐다고 알려짐.
- **이용처**: Cursor 전 요금제, Grok Build, xAI API 콘솔에서 이용 가능. EU는 아직 미지원.

## 왜 중요한가 (비개발자 관점)

같은 주(07-09) OpenAI의 GPT-5.6도 GA되면서, 하루 사이 세 프런티어 랩(Anthropic·OpenAI·xAI)의 모델이 모두 시장에 나와 있는 상태가 됐다. Grok 4.5는 최상위 모델군 중 가장 저렴한 축에 속해, "최고 성능"이 아니라 "성능 대비 가격"을 기준으로 모델을 고르는 기업이 늘어날 유인을 만든다.

## 활용/시사점

- **AX 관점**: 코딩·에이전틱 업무에 Claude Opus·GPT-5.6 Sol을 쓰던 조직이라면 Grok 4.5를 벤치마크 후보에 추가할 가치가 있다 — 단, EU 리전 미지원 등 가용성 제약은 확인 필요.
- Cursor와의 공동 학습 사례는 "에디터·툴 벤더가 모델 학습 데이터 파트너가 되는" 최근 추세(데이터 플라이휠)의 한 예시로 강의에 활용 가능.
