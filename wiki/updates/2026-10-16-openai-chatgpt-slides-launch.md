# ChatGPT Slides 출시 — 대화·파일·개요에서 바로 발표자료 생성·공동편집

## 무엇이 바뀌었나

OpenAI가 2026-10-16 **ChatGPT Slides**를 출시했다. Pro·Business·Enterprise 플랜(Space
접근 권한 보유)에 순차 롤아웃되며 웹·데스크톱 앱에서 쓸 수 있다.

- **생성 경로**: 대화 맥락, 업로드한 파일, 개요(outline)에서 바로 슬라이드 덱을 생성.
  참고 덱을 공유해 스타일·레이아웃을 따라가게 할 수도 있다.
- **편집**: 텍스트·이미지·도형·차트를 직접 수정하거나, ChatGPT에게 자연어로 수정을
  요청.
- **공동편집**: Space 안에서 동료를 초대해 같은 덱을 실시간 동시 편집, 공유 댓글 가능.
- **내보내기**: 웹에서는 PowerPoint·PDF·Google Slides로 내보내기, 데스크톱 앱에서는
  PowerPoint·Keynote가 설치돼 있으면 바로 열람.

## 왜 중요한가 (비개발자 관점)

발표자료 제작은 보고서 작성과 함께 사무직 업무에서 가장 반복적인 "형식 노동"에
속한다. ChatGPT가 이 작업을 대화 한 번으로 끝내고, 팀원과 같은 문서를 동시에
고치게 해준다는 것은 — 이미 Claude Code 등 개발자 도구에서 검증된 "자연어로 지시 →
결과물 생성 → 반복 수정" 패턴이 **비개발 사무직의 일상 업무(슬라이드 제작)로 그대로
옮겨왔다**는 뜻이다. Microsoft Copilot·Google Workspace(Gemini)의 슬라이드 생성
기능과 바로 경쟁하는 영역이다.

## 활용/시사점

- **강의**: "프롬프트 몇 줄로 보고서 초안 슬라이드 만들기" 실습에 바로 쓸 수 있는
  최신 기능 — 참고 덱 업로드로 조직의 기존 템플릿 스타일을 유지하는 법을 함께
  가르치면 실무 전환이 빨라진다.
- **AX**: Space 기반 공동편집은 "문서를 돌려가며 고치는" 기존 결재·검토 프로세스를
  "같은 문서를 동시에 보며 고치는" 방식으로 바꿀 잠재력이 있다 — 보고서·제안서 작성
  워크플로 재설계 시 참고할 사례.
