# xAI, Grok 4.6 출시 — Grok 4.5 이후 35일 만, 롱런 에이전트 작업 강화

## 무엇이 있었나

xAI가 [[2026-07-09-xai-grok-4-5-launch|Grok 4.5]] 출시 35일 만에 후속 모델 **Grok 4.6**을
출시했다(2026-08-12). 여러 단계에 걸친 장기 실행 에이전트 작업(리서치·코드베이스 분석·
앱 제작 등)에 초점을 맞춘 개발자 우선 릴리스.

- **가격**: 입력 $2/출력 $6(백만 토큰당, 20만 토큰 이하 프롬프트 기준) — Grok 4.5와 동일
  가격 유지. 20만 토큰 초과 시 $4/$12로 두 배.
- **성능**: Artificial Analysis Intelligence Index 기준 54 → 61로 상승, GPT-5.6 Sol Max와
  동급(61점) 수준.
- 체크포인트 날짜 2026-08-10, API 모델 ID는 `grok-4.6`.
- 후속 로드맵(업계 추정): Grok 4.7(2.1조 파라미터)이 수 주 내, Grok 5는 2026년 말 목표로
  거론된다.

## 왜 중요한가 (비개발자 관점)

한 달여 만에 또 한 세대를 올리는 xAI의 출시 속도 자체가 프론티어 모델 경쟁의 압축된
사이클을 보여준다. 가격은 그대로 두고 성능만 끌어올렸다는 점에서, "AI 모델 = 갈수록
저렴해지는 상품"이라는 최근 추세를 다시 확인시켜준다.

## 활용/시사점

- **AX**: 코딩·에이전틱 업무에 Claude Opus·GPT-5.6 Sol을 쓰던 조직이라면 Grok 4.6도
  벤치마크 후보에 추가할 가치가 있다 — 동일 가격에 성능이 개선됐기 때문. 다만 20만 토큰
  초과 시 가격이 두 배로 뛰는 구조는 장문 컨텍스트 작업의 실비용 계산에 반영해야 한다.
- 5주 간격의 출시 속도는 "모델 선택을 고정하지 말고 주기적으로 재평가하라"는 AX 원칙의
  근거로 쓸 수 있다.
