# OpenAI is building an AI agent for everything. Will everyone use them? (TechCrunch, 2026-08-24)

## 요약 (WebFetch 정리)

OpenAI는 지난달 **ChatGPT Work**를 출시했다. 이는 소프트웨어 엔지니어 중심의 AI
에이전트를 일반 사무직 종사자까지 확대하려는 전략이다.

### 주요 기능 및 접근성
데스크톱·모바일 앱이 사용자의 이메일, Slack, 전화, Notion, Figma 등에 직접 접근하고
제어한다. 월 20달러 구독료로 제공되며, 복잡한 다단계 작업을 자동으로 완료할 수 있다.

### 채택 현황 (2026년 8월 기준)
- OpenAI 내부 직원 98% 사용 중
- 외부 조직 구독자 17%
- 개인 구독자 1% 미만

### 중요성
OpenAI 임직원에 따르면 "소프트웨어 개발자만 대상으로는 제한적"이며, 회계사, 의사,
투자자 등 다양한 직군으로 확대해야 수익을 정당화할 수 있다.

### 우려 사항
- 복잡한 권한 설정으로 혼동 초래
- 비용 문제: 4일간 casual 사용으로 약 8,000만 토큰 소비, $65 비용 발생
- 모델이 개인정보를 실수로 공유할 가능성
- 코드와 달리 업무 성과 평가가 어려움
