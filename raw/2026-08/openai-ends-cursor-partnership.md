## 요약 (WebSearch 종합)

- SpaceX가 2026-08-14 Cursor(개발사 Anysphere) 인수를 공식 완료(전량 주식 거래, 약 $60B,
  SpaceX Class A 주식 약 3.91억 주 발행 — 스타트업 인수 사상 최대 규모). Cursor는 신설
  "SpaceXAI" 산하 완전자회사로 편입, SpaceX Colossus 슈퍼컴퓨터 접근권 확보, Grok Bot 베타
  이미 출시(2026-08-11, [[2026-08-11-spacexai-grok-bot-launch]] 기존 반영).
- 인수 완료 2주 만인 2026-08-28~29, OpenAI가 Cursor에 대한 자사 모델(GPT 계열) 직접 API
  접근을 2026-11-12부로 종료한다고 공식 발표.
- 사유: Musk 연관 기업들의 "계약 파기 이력"을 명시적으로 근거로 제시 — Anthropic이 2025년
  Windsurf 인수 논의 당시 취했던 조치("Anthropic did to Windsurf")와 동일한 패턴으로 해석됨.
  OpenAI-related 데이터·기술의 부적절한 사용을 둘러싼 기존 분쟁 이력도 언급.
- 영향은 제한적: Cursor 공동창업자 Michael Truell은 OpenAI 모델이 Cursor 트래픽의 5%에
  불과하다고 평가절하. 사용자는 본인 OpenAI API 키로 계속 접근 가능하며, OpenAI가 제공하는
  IDE 확장 경유 접근은 유지.
