# AX LABS — "모델은 그대로, 에이전트만 좋아지게 하는 법"

- 원문: https://theaxlabs.com/blog/harness-r1-failure-driven-harness-editing
- 게시일: 2026-08-10 (AX LABS 블로그, "에이전트 제품 설계" 카테고리)
- 수집일: 2026-08-19

## 요지

모델을 재학습하지 않고 에이전트 성공률을 9.3%p 올린 Harness-R1 논문을 실무 관점으로
풀었다. 하네스가 무엇인지, 개입할 수 있는 네 지점이 어디인지, 그리고 논문의
실패→수정→재실행 루프를 GPU 없이 Claude Code에서 그대로 돌리는 프롬프트 4개를 정리.

## 핵심 내용

- **논문 결과**: 3개 벤치마크 평균 성공률 44.3%→53.6%(+9.3%p). 9B 소형 특화 모델이
  하네스 최적화만으로 대형 LLM을 능가 — "검증 루프가 결과를 갈랐다."
- **하네스 개입 4지점**:
  1. 사전 브리핑(CLAUDE.md·시스템 프롬프트)
  2. 단계별 체크리스트(실행 중 상태 힌트)
  3. 사전 체크포인트(실행 전 검증)
  4. 사후 오류 복구(에러 핸들링·가이드)
  — 연구 결과 3·4번(사전검증·사후복구)이 성능에 가장 큰 영향.
- **4단계 주간 루틴**(Claude Code 적용):
  1. 실패 패턴 수집 — 로그에서 반복 실패 추출·분류
  2. 수정안 설계 — 근본 원인 겨냥한 좁고 재사용 가능한 개입안 생성
  3. 재실행 검증 — 과거 실패 태스크를 새 설정으로 재실행
  4. 회귀 테스트 — 과거 성공 태스크가 깨지지 않는지 확인
- GPU·모델 재학습 불필요, Claude 기반 분석과 환경(CLAUDE.md·훅) 수정만으로 매주
  반복 가능하도록 설계.
- **측정 수치**: 논문 수치(44.3%→53.6%)만 존재 — Claude Code에 이 루틴을 적용한
  실측 사례·수치는 글에 없음.
