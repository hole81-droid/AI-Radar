## 요지

개인별 AI 채팅에 흩어진 업무 교정·규칙을 조직 공용 지식베이스("컴퍼니 브레인")로
통합하는 프롬프트 6종과 1주 재현 가이드.

## 핵심 내용

프롬프트 6종: ① 기존 지능 추출(지난 30일 채팅에서 규칙 발굴) ② 지도 파일(우선순위·
진실의 출처) ③ 교정을 원인(정책/지식/스킬)으로 분류 ④ 워커 명세화 ⑤ 반대편 심사
(회사 기본값 승격 전 검토) ⑥ 주간 헬스체크.

- 승격 기준: "3회 규칙" — 서로 다른 사람의 3번째 동일 교정부터 정책화.
- 파일 저장 규격 예시: Claude Code `CLAUDE.md`, Agentic AI Foundation `AGENTS.md`.
- 특정 도구 비종속 — Claude Code·Cursor·ChatGPT·Gemini CLI·Copilot 모두 언급.
- 구체적 고객사 사례·정량 수치 없음, 가상 시나리오(영업·마케팅·개발팀) 기반 설명.
- 참고: J.B.(@VibeMarketer_)의 X 게시물 + Anthropic 문서 + AGENTS.md 오픈소스 표준을
  근거로 정리한 것으로 보임(원문 명시).
