# The Claude in Chrome side panel is now Claude Cowork

- 출처: https://claude.com/blog (블로그 목록에서 제목·날짜 확인, 개별 글 URL 404로 9to5mac 요약으로 보강)
- 보강 출처: https://9to5mac.com/2026/08/12/claude-cowork-chrome/
- 발행일: 2026-08-12
- 수집: WebFetch 요약

## 무엇이 바뀌었나

- Claude in Chrome의 사이드패널이 이제 별도 선택 없이 곧바로 정식 Claude Cowork 세션으로 시작된다.
- 브라우저 확장에서 시작한 대화가 Claude 히스토리에 저장되어 데스크톱·웹·모바일 앱에서 이어서 진행 가능.
- 계정에 이미 설정된 Skills·커넥터가 브라우저에서도 별도 설정 없이 그대로 동작.
- Claude가 현재 로그인된 페이지를 읽고, 링크 클릭·페이지 이동·텍스트 입력·폼 작성을 수행. 예: 여러 벤더 사이트에서 인보이스 데이터를 수집한 뒤 데스크톱에서 이어서 정리.

## 제공 범위
- Max·Team 고객: 즉시 사용 가능
- Pro 플랜: 향후 수 주 내 순차 롤아웃
- Enterprise 관리자: 기능 활성화 및 승인 도메인 제한 가능

## 한계·안전장치
- Chrome 전용, 타 Chromium 브라우저·모바일 브라우저는 아직 미지원
- Anthropic도 "브라우저 에이전트는 프롬프트 인젝션에 취약하다"고 인정, 결제·데이터 공유 등 중요 행동 전에는 검토·확인 절차 유지
