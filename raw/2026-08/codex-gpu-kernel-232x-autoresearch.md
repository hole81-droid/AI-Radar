# Codex "/goal" 에이전트 루프로 GPU 커널 232배 가속 — GPU Mode 리더보드 참가기

- 원문: https://sankalp.bearblog.dev/autoresearch/
- HN 토론: https://news.ycombinator.com/item?id=49309549 (361점)
- 게시일: 2026-08-15 무렵 (HN 스캔 시점 2026-08-16 기준 당일 프론트페이지)
- 수집일: 2026-08-16

## 요약

- **도구**: 1차 GPT-5.5(ChatGPT Pro "Codex", 연 $200 구독) 에이전트 루프. 보조로 Claude
  Pro(연 $20 구독)를 아이디어 자문역으로 활용. GPU 프로파일링 인프라는 Modal(월 $30 무료
  크레딧 포함).
- **과제**: NVIDIA B200 GPU에서 배치 QR 분해(batched QR decomposition) 커널 최적화 —
  `torch.geqrf` 출력 포맷을 맞추면서 32×32~4096×4096 전 구간에서 속도를 극대화.
- **에이전트 루프 구조**:
  - Codex의 `/goal` 지시어로 장시간(24시간+) 무인 최적화 세션 유지.
  - `/btw`, `/side` 명령으로 루프를 멈추지 않고 비차단(non-blocking) 방식으로 사람이 개입.
  - 프로파일링 분석·아이디어 생성·버그 헌팅용 서브에이전트 별도 배치.
  - 단일 최적해에 집착하는 힐클라이밍 대신 3~5개 후보 계열을 동시에 유지하는 빔서치 방식.
  - 막힐 때 Claude를 자문역으로 불러 아이디어 다양성 확보.
  - 핵심 기법: Blocked Householder 알고리즘 + WY-update 압축, Triton·CUDA 커널(패널
    특화), CUDA 그래프 리플레이로 launch 오버헤드 절감, 점진적 알고리즘 라우팅
    (torch.geqrf → blocked WY → 커스텀 패널 → fused assembly).
- **성과**: 기준 대비 **232배** 속도 향상(419ms → 1.8ms 기하평균). 14일간 1,500개+ 제출,
  560개 이름 붙은 변형 아카이브, Modal 프로파일링 스크립트 119개. 최종 기록 1,805
  마이크로초(시작점 108,803마이크로초 대비 −98.34%), GPU Mode 리더보드 183명 중 12위.
- **재현성**: GPU Mode 리더보드 인프라(자동 채점기가 직교성·삼각행렬 제약 검증, 형태별
  타이밍 피드백 제공, popcorn CLI로 에이전트 자동 제출)로 공개 검증 가능. 단 B200 하드웨어
  접근 장벽으로 개인 재현은 비용·시간 부담이 큼.

## 참고

  맥락(경쟁 채점 기준)이라 실무 프로덕션 배포 사례와는 성격이 다르다는 점을 명시해야 한다.
