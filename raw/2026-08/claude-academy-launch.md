# Anthropic, "Claude Academy" 무료 학습 허브 출시

- 원문: https://claude.com/blog/anthropics-approach-to-teaching-and-learning-ai (공식 발표), https://explainx.ai/blog/claude-academy-launch-4d-ai-fluency-framework-august-2026 (요약)
- 게시일: 2026-08-20
- 수집일: 2026-08-22 (WebSearch로 대조, claude.com 공식 블로그 확인)

## 요지

Anthropic이 사내 직원 트레이닝 방식을 그대로 옮긴 무료 온라인 학습 플랫폼 "Claude Academy"를
2026-08-20 오픈했다. anthropic.skilljar.com에서 신용카드 없이 가입 가능, 약 20개 자체 페이스
코스를 제공하며 수료 시 인증서를 준다.

## 핵심 내용

- 커리큘럼은 완전 초심자용 "Claude 101"부터 Claude API·Claude Code 활용까지 기술 난이도별로
  구성.
- Anthropic의 메시지: 모델 지능이 계속 높아질수록 엔지니어뿐 아니라 모든 사용자가 AI를
  안전하고 효과적으로 쓰는 법을 알아야 한다는 취지.
- 무료 교육 자원을 구조화된 플랫폼으로 확장해 Claude 채택을 늘리려는 전략의 일환.
- [[2026-07-15-claude-for-teachers]](미국 K-12 교사 대상 무료 제공)와 함께 Anthropic의
  "교육 접근성" 라인업을 이룬다.

## 참고

- Claude Academy는 회사 자체 코스이고, Claude for Teachers는 기존 K-12 교육과정 커넥터
  지원이 중심이라는 점에서 대상·성격이 다르다.
