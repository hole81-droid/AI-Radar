## 요지

Anthropic이 Claude의 메모리를 Chat과 Cowork 사이에 통합했다. 지금까지 분리돼 있던 두 표면의
기억이 하나로 합쳐져, 어느 쪽에서 쌓은 맥락이든 다른 쪽에서 그대로 이어받는다.

## 핵심 내용

- Settings > Memory 탭 신설: 토글 2개(메모리 생성 여부 / 민감 주제 포함 여부) + Topics
  목록(기억된 내용을 짧은 파일 단위로 나열, 개별 열람·수정·삭제 가능) + 전체 초기화.
- 실시간 갱신: 대화 중 언급한 변경사항(예: 마감일 변경)이 별도 요청 없이 다음 대화부터 반영.
- 민감 주제(건강·인종/민족·종교·정치 성향·성 정체성) 기본 미저장, 토글로 별도 허용 가능.
- Free·Pro·Max 플랜, 웹·데스크톱·모바일 전체에서 기본값 켜짐.

## 수집 메모

WebSearch로 취합한 요약이며, 공식 헬프센터 문서(support.claude.com) 링크로 1차 출처를
확인했다. 원문 전문을 WebFetch로 정독하지는 않았음 — 세부 UI 문구 등은 공식 문서 직접 열람
시 재확인 필요.
