## 영상 설명(shortDescription) 원문 발췌

입찰 공고, 채용 공고, 리뷰 데이터. 필요할 때마다 한 건씩 복사·붙여넣기 하고 계신가요?
이런 분들을 위해 웹 크롤링 에이전트 'web-crawler'를 무료로 공개합니다.

이 에이전트를 Claude Code나 ChatGPT Work에서 셋팅하고, URL을 붙여넣고 무엇을 모을지
한 줄로 설명하면 끝입니다. 에이전트가 알아서 사이트를 정찰하고, 사이트에 맞는 수집
코드를 짜고, 엑셀로 정리해 줍니다.

나라장터 입찰 공고 140건, 금감원 보도자료와 첨부 PDF 107개, 쿠팡 리뷰 1,000건. 로그인해야
보이는 네이버 카페와 인스타그램까지 실제로 수집해 봤습니다.

영상 후반부에는 이 에이전트를 각자 업무에 맞게 '개량'하는 세 가지 방법과, 크롤링의
법적 기준 여섯 가지, 그리고 AI와 함께 일 잘하는 방법에 대한 생각도 담았습니다.

## GitHub README 요약 (WebFetch 정독)

- 기술 스택: Python 3.10+ + Scrapling, Node.js 18+ 기반 agent-browser(정찰),
  Playwright/Chromium, openpyxl(엑셀 출력).
- 설치: Windows `scripts\setup.ps1`, macOS/Linux `scripts/bootstrap.py` 원커맨드.
- 워크플로: 입력 파싱 → 정찰 → 전략 선택(정적/세션/동적/안티봇) → 수집스크립트 생성·
  실행 → 검증·도메인 프로필 저장.
- 안전장치: 접근제한 우회 시 사용자 확인, robots.txt+속도제한, PII 탐지 경고,
  CAPTCHA/자격증명 자동처리 금지, 화이트리스트 기반 도메인 프로필 배포.
- 라이선스 MIT, 사전 설정 도메인 프로필 14개, `ACCEPTABLE_USE.md`로 법적 사용범위 안내.
