# Nvidia Open Agent Safety Platform

- 원문: https://nvidianews.nvidia.com/news/open-agent-safety-platform
- 수집일: 2026-09-29 (발행 2026-09-28)

## 요약 (WebSearch 종합)

Nvidia가 Open Agent Safety Platform을 발표. OpenShell(무료 오픈소스 런타임)과
Sentry(Nvidia BlueField-4 DPU에서 독립 동작하는 하드웨어 워치독, 밀리초 단위 격리)로 구성.
100여 개 런칭 파트너(Anthropic·Microsoft·JPMorgan Chase·Palantir·Cisco·SpaceXAI 등) 참여.
Anthropic은 Claude Managed Agents를 OpenShell·BlueField와 통합, SpaceXAI는 Cursor 코딩
에이전트·Grok 모델에 적용.
