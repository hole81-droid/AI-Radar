# Anthropic — Claude Code Cloud sessions 정식 출시(GA)

## 요지

Anthropic이 Claude Code **Cloud sessions**를 리서치 프리뷰에서 정식 출시(GA)로
전환하고, Pro·Max 구독자에게 1회성 크레딧(Pro $100 / Max $250)을 제공했다. 09-19
발표된 "Projects" 재설계([[2026-09-19-claude-code-projects-cloud-session-coordination]])가
기반으로 삼던 클라우드 세션 인프라 자체가 이번에 정식 단계로 넘어간 것.

## 핵심 사실

- 09-23 발표, GitHub 계정 연동 필요, 크레딧은 10-07까지 신청해야 하며 11-04 만료.
- 접근 경로 4가지: claude.ai/code 브라우저, 모바일 앱 Code 탭, 데스크톱 클라이언트
  클라우드 토글, 터미널 `claude --cloud "작업 설명"`.
- 컴퓨터를 꺼도 Anthropic 클라우드 인프라에서 작업이 계속 진행. 추가 VM 요금 없음,
  크레딧 소진 후에는 표준 구독 한도 적용.

## 맥락

- 09-19 Projects 페이지에 "09-23 후속"으로 반영.
