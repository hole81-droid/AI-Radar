# 1편. (완결판) 따라하기만 하면 되는 클로드코드 업무 자동화

비개발자도 클로드코드와 함께 업무 자동화할 수 있다!

## 클로드코드!! 도대체 뭔데!!!!

클로드코드를 배우고 싶지만 공식 문서는 개발자 언어로 가득하고, 유튜브는 바이브코딩(앱/웹 개발)뿐이라 실무 업무 자동화에 어떻게 쓰는지 몰랐던 분들을 위해 인프런에 강의가 나왔습니다.

클로드코드, 실은 '바이브코딩툴'이라고 하기엔 할 수 있는 일들이 너무나 광범위합니다.

저희가 클로드와 같은 AI 채팅에서 이야기를 나누고, 조언을 듣고, 실행은 직접해야 했다면, 클로드 코드는 내 컴퓨터의 파일, 폴더에 접근 권한이 있고 코딩 능력을 이미 가지고 있기 때문에 조언, **전략부터 실행까지 다 해주는 게임 체인저**라고 볼 수 있습니다.

예시:
- "이 PDF 10개를 하나로 합쳐줘" → AI: (즉시 실행) merged_report.pdf 생성 완료
- "엑셀 A, B, C열만 추출해서 새 파일로" → AI: (즉시 실행) extracted_data.xlsx 다운로드 가능

## 설치

*유료 사용자만 사용 가능*

1. Node.js 설치 (v18 이상)
2. 맥: 터미널 / 윈도우: Git Bash
3. `npm install -g @anthropic-ai/claude-code`

## 폴더 구조 이해

클로드 코드는 폴더 구조를 이해해서 일을 합니다. 폴더 경로를 주면 그 안의 자료들을 확인합니다.

참고 자료 기반 PPT를 자동으로 만드는 업무를 예시로, 제대로 스킬·에이전트 등을 구성한다면 폴더와 지침을 구성. **주의: 이 폴더들은 우리가 만드는 게 아니라 클로드 코드가 알아서 만들어준다.**

### .md 파일이란?
마크다운 파일. 텍스트에 #, * 등으로 서식을 지정한 텍스트 파일. 프로젝트 메인 설정(CLAUDE.md), skill, agents 모두 .md로 작성 — "역할이 명확히 부여되고 구성 요소를 잘 갖춘 프롬프트 텍스트 파일".

- **CLAUDE.md**: 프로젝트 메인 설정
- **skill.md**: 기능 정의 — 다른 사람들이 만든 스킬은 skillsmp.com에서 다운로드 가능
- **agent.md**: 에이전트 역할 지정

## 시작하기

1. 빈 폴더를 만들고 `cd 폴더경로`로 이동, `claude` 실행
2. 작업 폴더에 '프로젝트 셋팅 가이드' 파일(잘 쓰는 사람들의 경험담을 모은 문서)을 넣고 경로를 붙여넣기
3. 요청 예시:

> 이 파일 참고해서 '사이트 주소와 컨텐츠 주제를 넣으면, 사이트 내 브랜드 관련 내용을 에셋으로 저장한 후 참고해서 인스타 카드뉴스, 릴스 시나리오, 링크드인 글, 스레드 글로 써주는 프로젝트'를 만들어줘.

4. 승인을 위해 계속 1을 누르면 에이전트와 스킬들을 만들어준다. 이후 프롬프트로 업무를 시킨다.

## 요약
1. 클로드코드로 자동화할 업무를 고르자
2. 빈 폴더를 만들고, 클로드코드에게 '이 업무에 적합한 프로젝트 셋팅해줘'라고 요청 (잘하는 사람들의 노하우 문서를 참고시키고, 만드는 것도 클로드코드에게 시킨다)
3. 프롬프트로 그 업무를 시킨다

## ❶ 클로드코드가 뚝딱 만들어주는 노션 백서 & 캘린더

배경: 링크드인 강의 출시와 함께 328쪽 PPT 자료를 다양한 형태로 변환할 필요.

### 미션1: PPT → .md(마크다운) 변환
- 스킬 = 클로드에 장착하는 '손발' (실시간 데이터 접근, 정확한 연산·처리, 외부 서비스 연동, 할루시네이션 방지)
- 스킬 구하기: https://skills.sh/ 검색, 또는 클로드에 직접 요청해 생성
- 왜 클로드코드인가: 328장 PPT는 첨부 용량 제한(31MB 이상 불가)과 컨텍스트 한계 초과. 클로드코드는 "용량 제한도, 컨텍스트 제한도 훨씬 크고, 알아서 한 번에 할 수 있는 작업을 분할하고, 다 될 때까지 반복"

### 미션2: 노션 문서 생성
- 클로드코드와 노션 API 연동
- 마크다운 기반으로 꿀팁 모음, 프롬프트 모음집, 90일 캘린더 자동 생성

### 결과
