## 사례 1. 다운로드 폴더 자동 정리
- 업무: 파일 종류별/프로젝트별 자동 분류
- 방법: "파일 종류별로 정리해줘" 프롬프트로 확장자·내용 기반 분류
- 성과: 수백 개 파일을 몇 분 내 정렬

## 사례 2. 리서치 → 발표자료 원스톱 생성
- 업무: 시장조사, 보고서 작성, 슬라이드 제작
- 방법: "SaaS 시장에서 AI 에이전트 트렌드 조사해줘" 한 프롬프트로 조사→정리(마크다운·Excel)→발표자료 3단계 완료
- 브랜드 가이드(색상 코드·폰트·로고)를 미리 제공하면 디자인 맞춤

## 사례 3. 영수증 → 경비 보고서 자동 생성
- 업무: 영수증 데이터 추출 및 경비 보고서 작성
- 방법: 영수증 사진/PDF를 폴더에 저장 후 "경비 보고서 만들어줘" 요청
- 추출 항목: 가맹점명, 날짜, 금액, 항목, 카테고리 자동 분류
- 성과: **매달 2시간 → 10분으로 단축**

## 사례 4. 매일 아침 브리핑 문서 자동 생성
- 업무: 다채널 정보 통합 일일 브리핑 (대상: 매니저·팀 리드)
- 방법: Slack·Notion·팀 대시보드를 MCP 커넥터로 연결
- 대상 정보: 팀 활동, 우선순위, 중요 항목
- 성과: Slack 스크롤 시간 절약

## 사례 5. 데이터 분석 & 시각화 리포트
- 업무: 데이터 수집·정리·트렌드 분석
- 방법: PostHog, Google Analytics 연동 후 "지난 30일 DAU 데이터 정리해서 트렌드 분석해줘"
- 분석: 급락 원인 추론·인사이트 제공
- 성과: 분기 보고서 준비 시 raw 데이터 처리 시간 절약

## 사례 6. 이메일 정리 & 우선순위 분류
- 업무: 수신 메일 관리 및 자동 정렬
- 방법: Gmail 연동, "긴급 메일 정리, 나머지 카테고리별 요약"
- 기능: 중요 메일 상단 배치, 뉴스레터 분류, 답장 초안 작성
- 성과: **아침 메일함 정리 30분 절약**

## 사례 7. 커스텀 스킬로 반복 업무 자동화
- 방법: 브라우저 동작 녹화 → 패턴 학습 → 자동 재현
- 예시: "매주 월요일 사이트에서 데이터 뽑아 정해진 형식으로 정리"
- 추가 자원: Anthropic 오픈소스 플러그인 11개 (영업·법무·재무·마케팅·데이터 분석·개발)
- 코딩 불필요

## 기타
- 한국어 최적화는 아직 부족 — 언어 의존도 낮은 작업(파일 정리·데이터 추출)부터 시작 권장
- Claude Code와의 조합: 비개발자가 Cowork로 PRD 작성 → 개발자가 Claude Code로 구현
- 원문에 없는 것: 사례별 권한 설정, 사용 모델, 저자 직업/소속
