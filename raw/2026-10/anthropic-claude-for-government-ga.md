# Claude for Government GA + Claude Code/M365 조기접근 (WebSearch 교차확인 캡처)

- Claude for Government이 2026-09-30 FedRAMP High 인증 환경에서 정식 출시(GA),
  2026-07 공개 베타 이후 약 2개월 만.
- 관리 기능: 선불 사용량 하드캡, 사용자그룹별 지출·모델 한도, 사용량 모니터링·잔액
  알림, 관리자 작업 감사 로그, 민감 작업 2인 승인(two-person approval).
- 업무 기능: 데스크톱 파일 직접 작업, Skills·Plugins·Projects로 메모 작성·RFP 검토·
  케이스워크 수행.
- 같은 FedRAMP High 환경에서 Claude Code CLI(정부 SW 개발용)·Claude for Microsoft
  365(정부 생산성 업무용) 조기접근(early access) 동시 시작.
- 같은 주(10-01) Barclays가 Claude를 운영·고객경험 업무로 확대 적용한다고 발표
  (세부 수치 미확인).
- 이 발표는 09-30~10-03 데일리 스캔에서 전부 누락돼 10-04에 소급 반영.
