# Epic Games — 게임 런처를 "vibe coding"으로 전체 재작성, Steam 대비 46% 빠르다고 발표 후 Valve가 역전

> 수집: 2026-10-16 스캔. HN("Steam Client is now faster than Epic's new vibe coded
> launcher", 240점, 2026-10-15) 발견 후 WebSearch로 원문 교차확인(PC Gamer·Tom's
> Hardware·Kotaku·Windows Central·Engadget·Neowin·Destructoid 다수 보도).

## 핵심 내용

- Epic Games가 공식 블로그에서 Epic Games Store 런처(클라이언트)를 **"vibe coded"**
  (AI에게 평문으로 지시해 코드를 생성하는 방식)로 **처음부터 새로 작성**했다고 발표.
  "We started from scratch" — 기존 기능은 참고했지만 코드 자체는 재사용하지 않았고,
  완전히 다른 기술 스택으로 새 아키텍처를 만들었다고 밝힘.
- AI는 "새 기능을 밑바닥부터 작성·리뷰하는 도구"로 썼다고 설명 — 구체적으로 어떤 AI
  모델/도구(Claude·Codex·Gemini 등)를 썼는지는 공개 안 함(**미확인**).
  "Programming is hard"라는 반농담조 설명이 같이 붙었다.
- 성과 주장: 콜드스타트(앱 실행~스토어 페이지 표시) 평균 **5.47초**, Steam 대비
  **46% 빠르다**고 주장. 런처 시작 시간을 기존 대비 절반으로 줄였다고 설명.
- 현재 **프리뷰(베타) 단계**로 공개, 경쟁 게임 등 민감한 용도에는 권장하지 않는다는
  단서가 붙음(Tom's Hardware).
- **역풍**: 발표 직후 Valve가 Steam 클라이언트 업데이트를 내놓으며 체감 속도 우위가
  뒤집혔다는 평가가 나왔다(HN 제목 "Steam Client is now faster than Epic's new vibe
  coded launcher", 240점). Kotaku는 커뮤니티 반응을 인용해 "This Launcher Is So
  F*cking Vibeslopped Its Funny"라는 제목으로 조롱 수위의 반응을 소개.
- "vibe coded"라는 표현 자체를 자사 블로그에 직접 쓴 것이 이례적 — AI 비판 여론을
  의식하지 않는다는 신호로 받아들여짐(Engadget·PC Gamer 분석).
