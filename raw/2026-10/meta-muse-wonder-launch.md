## 핵심 사실

- Meta Superintelligence Labs가 2026-10-12 **Muse Wonder**·**Muse Wonder Full**을 발표.
  코딩·장시간 에이전트 작업·고급 컴퓨터 사용에 초점, 컨텍스트 윈도우 100만 토큰.
- Meta 마케팅 자료: Wonder Full이 SWE-Marathon 57.5%, Claude 대비 46.3% 우위를 주장(Opus
  5.5·GPT-6 Astra를 "지속형 에이전트 작업"에서 이겼다고 발표).
- 그런데 Meta가 **같은 자료에서 공개한 평가표 자체**는 다른 숫자를 보여준다 — SWE-Marathon
  79.0(57.5 아님), Opus 5.5 대비 격차 4.8점(11.2 아님). DeepSWE에서는 Wonder Full이
  3위(57.1)로 Opus 5.5(59.6)·GPT-6 Astra(59.1)보다 낮다.
- 독립 기관 Artificial Analysis 측정: Muse Wonder Intelligence Index 52(9위), Wonder Full
  56(4위) — 격차 4점. Meta 자체 "JobBench"의 44점 격차 주장과 모순.
- Meta 테이블 14개 지표 중 Wonder Full이 Claude Fable 5.1·GPT-6 Astra·Claude Opus 5.5
  상대로 7개에서 승리(과반을 살짝 넘김, "압도적 우위"는 아님).
- 가격: Muse Wonder API $4.00/백만 입력 토큰, $20.00/백만 출력. Wonder Full은 API 가격
  없이 구독제($50~200/월)로만 제공.

## 참고 — 기존 Muse(09-08 출시, 개인비서 에이전트)와의 관계

Muse Wonder/Wonder Full은 기존 "Muse"(2026-09-08 출시, 쇼핑·예약 대행 개인 에이전트,
[[2026-09-21-amazon-blocks-meta-muse-agent-commerce]] 참조)와는 **다른 제품**이다. 전자는
Meta의 프론티어 LLM 모델 패밀리(코딩·에이전트 작업용), 후자는 그 모델 위에 얹힌 소비자용
개인비서 앱. 이름이 같아 혼동 주의.
