## 핵심 내용

- Accenture가 2026-10-01부로 직원 1인당 Claude 중앙 지원 예산을 월 $29로 제한.
  일부 직원은 월 $500~$1,000를 쓰고 있었음.
- 한도 초과 시 프로젝트/팀의 WBS(Work Breakdown Structure) 예산코드로 청구.
- 배경: 2025년 12월 Accenture-Anthropic 다년 파트너십(약 3만 명 Claude 교육,
  수만 명 개발자에 Claude Code 배포 — Anthropic 사상 최대 Claude Code 배포).

## Reddit(r/AI_Agents, u/Panic_Lion) 실무자 분석 — 100+ 기업 Claude 롤아웃 경험 주장

전체 인용(5가지 체크리스트):
1. 주간 활성 사용자 수 보고를 중단하고, 수작업 핸드오프가 실제로 멈췄는지를 보고하라.
2. "Finance"처럼 통으로 된 Project 하나가 아니라, 반복 업무 하나당 Project 하나.
3. 커넥터(데이터 연동) 설정을 끝까지 마무리하라.
4. 최고 숙련자의 작업 방식을 Skill로 만들어라 — 프로세스 책임자가 아니라 실제
   그 일을 하는 사람 5명과 먼저 이야기하라.
5. 그런 다음에야 Cowork에 "완료"가 명확한 멀티스텝 작업을 맡기라.
