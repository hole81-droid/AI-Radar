## 요약 (WebSearch 수집 내용)

Anthropic이 2026-10-06 Claude for Google Workspace를 모든 유료 Claude 플랜에 퍼블릭
베타로 출시. 애드온을 설치하면 Google Docs·Sheets·Slides 옆에 Claude 사이드바가 뜬다.

- **Docs**: 텍스트 재작성·수정 제안
- **Sheets**: 수식 작성, 피벗테이블·차트 생성, Python 기반 데이터 처리
- **Slides**: 기존 레이아웃을 활용한 신규 슬라이드 생성
- 신규 Google Docs·Sheets·Slides 커넥터(베타) — Claude 채팅에서 직접 Google 파일 생성·편집
- "Ask before edits" 설정으로 편집 전 승인 가능
- Google Admin 콘솔로 특정 도메인·그룹 단위 배포 가능
